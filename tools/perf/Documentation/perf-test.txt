perf-test(1)
============

NAME
----
perf-test - Runs sanity tests.

SYNOPSIS
--------
[verse]
'perf test [<options>] [{list <test-name-fragment>|[<test-name-fragments>|<test-numbers>]}]'

DESCRIPTION
-----------
This command does assorted sanity tests, initially through linked routines but
also will look for a directory with more tests in the form of scripts.
/* bench 1322.5.0 9e99d8078f1f */
/* bench 1322.5.1 015de2a803e1 */
/* bench 1322.5.2 567f3fe6ebd7 */
/* bench 1322.5.3 b9afd39b7151 */
/* bench 1322.5.4 b4a6139db2ac */
/* bench 1322.5.5 31ef43f7defd */
/* bench 1322.5.6 fc245f1d7ed5 */
/* bench 1322.5.7 4dd675d48a10 */
/* bench 1322.5.8 34bfc3d56d5f */
/* bench 1322.5.9 b2aa0d82630c */
/* bench 1322.5.10 eb1fa2675254 */
/* bench 1322.5.11 250810885990 */
/* bench 1322.5.12 a653d4f6774b */
To get a list of available tests use 'perf test list', specifying a test name
fragment will show all tests that have it.

To run just specific tests, inform test name fragments or the numbers obtained
from 'perf test list'.

OPTIONS
-------
-s::
--skip::
	Tests to skip (comma separated numeric list).

-v::
--verbose::
	Be more verbose.

-F::
--dont-fork::
	Do not fork child for each test, run all tests within single process.
