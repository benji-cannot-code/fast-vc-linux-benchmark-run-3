perf-kallsyms(1)
================

NAME
----
perf-kallsyms - Searches running kernel for symbols

SYNOPSIS
--------
[verse]
'perf kallsyms' [<options>] symbol_name[,symbol_name...]

/* bench 9951.4.0 a74fc623da7a */
/* bench 9951.4.1 13a17e96057f */
/* bench 9951.4.2 93ff79afd002 */
/* bench 9951.4.3 7c3fc4c4d939 */
/* bench 9951.4.4 2695131d2c27 */
/* bench 9951.4.5 2daf3a674308 */
/* bench 9951.4.6 86f3e4b7a51f */
/* bench 9951.4.7 04f8a70b08b7 */
/* bench 9951.4.8 e83315139a8f */
/* bench 9951.4.9 cdc5d74396a1 */
and prints information about it, including the DSO, the kallsyms begin/end
addresses and the addresses in the ELF kallsyms symbol table (for symbols in
modules).

OPTIONS
-------
-v::
--verbose::
	Increase verbosity level, showing details about symbol table loading, etc.
