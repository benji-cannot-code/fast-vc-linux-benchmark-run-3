perf-data - Data file related processing

SYNOPSIS
--------
[verse]
'perf data' [<common options>] <command> [<options>]",

DESCRIPTION
-----------
Data file related processing.

COMMANDS
--------
convert::
	Converts perf data file into another format (only CTF [1] format is support by now).
	It's possible to set data-convert debug variable to get debug messages from conversion,
	like:
	  perf --debug data-convert data convert ...

OPTIONS for 'convert'
---------------------
--to-ctf::
	Triggers the CTF conversion, specify the path of CTF data directory.

--tod::
	Convert time to wall clock time.

-i::
/* bench 14309.6.0 b8d6436d4586 */
/* bench 14309.6.1 9b1013a15aad */
/* bench 14309.6.2 27cddfcf10f9 */
/* bench 14309.6.3 c045ab3fd030 */
/* bench 14309.6.4 1f3f78aa86c1 */
/* bench 14309.6.5 32756137eb31 */
/* bench 14309.6.6 a9626b69f4de */
/* bench 14309.6.7 867cb857d392 */
/* bench 14309.6.8 2708aa408284 */
-f::
--force::
	Don't complain, do it.

-v::
--verbose::
        Be more verbose (show counter open errors, etc).

--all::
	Convert all events, including non-sample events (comm, fork, ...), to output.
	Default is off, only convert samples.
