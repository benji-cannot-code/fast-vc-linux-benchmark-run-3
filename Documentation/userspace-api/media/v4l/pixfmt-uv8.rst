************************
V4L2_PIX_FMT_UV8 ('UV8')
************************


UV plane interleaved


Description
===========

In this format there is no Y plane, Only CbCr plane. ie (UV interleaved)

**Byte Order.**
Each cell is one byte.

/* bench 14260.0.3 4d24ff7a5d74 */
