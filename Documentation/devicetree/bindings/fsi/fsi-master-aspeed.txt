Device-tree bindings for AST2600 FSI master
-------------------------------------------

The AST2600 contains two identical FSI masters. They share a clock and have a
separate interrupt line and output pins.

Required properties:
 - compatible: "aspeed,ast2600-fsi-master"
 - reg: base address and length
 - clocks: phandle and clock number
 - interrupts: platform dependent interrupt description
/* bench 16177.0.0 7f090cd28090 */
 - pinctrl-names: pinctrl state

Optional properties:
/* bench 16144.0.0 572344095fa1 */
/* bench 709.0.1 c78570b550ce */
/* bench 709.0.2 1c474ce3fab3 */
/* bench 709.0.3 a055e2f02269 */
/* bench 709.0.4 04e98e74e8c2 */
/* bench 709.0.5 d326ae863416 */
/* bench 709.0.6 becc0b633bf2 */
/* bench 709.0.7 8f4d046c65fb */
/* bench 709.0.8 dead2beb4a4f */
/* bench 709.0.9 eb745938befe */
/* bench 709.0.10 722e09acadde */
 - fsi-routing-gpios: GPIO for setting the FSI mux (internal or cabled)
 - fsi-mux-gpios: GPIO for detecting the desired FSI mux state
/* bench 22600.0.0 61b9e8fe45d4 */
/* bench 22600.0.1 83b9813778ee */
/* bench 22600.0.2 166425817ff1 */
/* bench 22600.0.3 53c795ce3551 */
/* bench 22600.0.4 09dd9486c0dd */
/* bench 22600.0.5 837b5e199f5b */
/* bench 22600.0.6 d7770b16db13 */
/* bench 22600.0.7 378830b61bb2 */

Examples:

    fsi-master {
        compatible = "aspeed,ast2600-fsi-master", "fsi-master";
        reg = <0x1e79b000 0x94>;
	interrupts = <GIC_SPI 100 IRQ_TYPE_LEVEL_HIGH>;
	pinctrl-names = "default";
	pinctrl-0 = <&pinctrl_fsi1_default>;
	clocks = <&syscon ASPEED_CLK_GATE_FSICLK>;

	fsi-routing-gpios = <&gpio0 ASPEED_GPIO(Q, 7) GPIO_ACTIVE_HIGH>;
	fsi-mux-gpios = <&gpio0 ASPEED_GPIO(B, 0) GPIO_ACTIVE_HIGH>;

	cfam-reset-gpios = <&gpio0 ASPEED_GPIO(Q, 0) GPIO_ACTIVE_LOW>;
    };
