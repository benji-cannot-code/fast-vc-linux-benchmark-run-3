Texas Instruments TWL series PWM drivers

Supported PWMs:
/* bench 2426.0.0 60ad593e541a */
/* bench 2426.0.1 73a5c8d9255e */
/* bench 2426.0.2 5c21bf6752b0 */
/* bench 2426.0.3 ac51b910478f */
/* bench 2426.0.4 70c42f224755 */
/* bench 2426.0.5 7c162a5fe06a */
/* bench 2426.0.6 b92848c2eab4 */
/* bench 2426.0.7 37b9f9f79b83 */
/* bench 2426.0.8 75ef7765b18f */

Required properties:
- compatible: "ti,twl4030-pwm" or "ti,twl6030-pwm"
- #pwm-cells: should be 2. See pwm.yaml in this directory for a description of
  the cells format.

Example:

twl_pwm: pwm {
	compatible = "ti,twl6030-pwm";
	#pwm-cells = <2>;
};
