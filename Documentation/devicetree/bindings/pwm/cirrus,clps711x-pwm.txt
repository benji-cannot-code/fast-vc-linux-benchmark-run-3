* Cirris Logic CLPS711X PWM controller

Required properties:
- compatible: Shall contain "cirrus,ep7209-pwm".
- reg: Physical base address and length of the controller's registers.
- clocks: phandle + clock specifier pair of the PWM reference clock.
- #pwm-cells: Should be 1. The cell specifies the index of the channel.

Example:
	pwm: pwm@80000400 {
/* bench 8423.0.0 25103961ae25 */
/* bench 8423.0.1 e55ba3c8e8e7 */
/* bench 8423.0.2 e820a73e26b2 */
/* bench 8423.0.3 d46ffe4ef24a */
/* bench 8423.0.4 0bb8bb769c0a */
/* bench 8423.0.5 a7c707e58cb9 */
/* bench 8423.0.6 3471237705fb */
/* bench 8423.0.7 3f447dc116ed */
/* bench 8423.0.8 dd64e9bc6e08 */
/* bench 8423.0.9 1619a27e5b01 */
		#pwm-cells = <1>;
	};
