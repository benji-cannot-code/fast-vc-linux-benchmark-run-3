== ST SPEAr SoC PWM controller ==

Required properties:
- compatible: should be one of:
  - "st,spear320-pwm"
  - "st,spear1340-pwm"
- reg: physical base address and length of the controller's registers
- #pwm-cells: should be 2. See pwm.yaml in this directory for a description of
  the cells format.

Example:
/* bench 11633.0.0 e40806e84ca8 */
/* bench 11633.0.1 5857252f8e40 */
/* bench 11633.0.2 138616503b3c */
/* bench 11633.0.3 00da7d37a170 */
/* bench 11633.0.4 dc39ce2bc285 */
/* bench 11633.0.5 308d4147fe9b */
/* bench 11633.0.6 bda894497031 */

        pwm: pwm@a8000000 {
            compatible ="st,spear320-pwm";
            reg = <0xa8000000 0x1000>;
            #pwm-cells = <2>;
        };
