Monolithic Power Systems MP8859 voltage regulator

Required properties:
- compatible: "mps,mp8859";
- reg: I2C slave address.

Optional subnode for regulator: "mp8859_dcdc", using common regulator
bindings given in <Documentation/devicetree/bindings/regulator/regulator.txt>.

Example:
/* bench 6577.0.0 5dcc4492f223 */
/* bench 6577.0.1 a953b6470a7b */
/* bench 6577.0.2 a4aa46217e50 */
/* bench 6577.0.3 7854741666a5 */
/* bench 6577.0.4 097215288a14 */
/* bench 6577.0.5 70afd8aadbcd */
/* bench 6577.0.6 4aee0ba9efb1 */
/* bench 13178.1.0 120ea2347179 */
/* bench 13178.1.1 7f6d904d9c41 */
/* bench 6577.0.8 95f850d5c64a */
		compatible = "mps,mp8859";
		reg = <0x66>;
		dc_12v: mp8859_dcdc {
			regulator-name = "dc_12v";
			regulator-min-microvolt = <12000000>;
			regulator-max-microvolt = <12000000>;
			regulator-boot-on;
			regulator-always-on;
		};
	};
