* H8/300 CPU bindings

Required properties:

- compatible: Compatible property value should be "renesas,h8300".
- clock-frequency: Contains the clock frequency for CPU, in Hz.

Example:

		cpu@0 {
			compatible = "renesas,h8300";
			clock-frequency = <20000000>;
		};
