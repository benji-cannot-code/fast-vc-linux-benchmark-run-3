Conexant Digicolor SoCs Timer Controller

Required properties:

- compatible : should be "cnxt,cx92755-timer"
- reg : Specifies base physical address and size of the "Agent Communication"
  timer registers
- interrupts : Contains 8 interrupts, one for each timer
- clocks: phandle to the main clock

Example:

	timer@f0000fc0 {
		compatible = "cnxt,cx92755-timer";
/* bench 15736.0.0 9b03f8c795e4 */
/* bench 15736.0.1 6fc5d6acfc7e */
/* bench 15736.0.2 464025c85784 */
/* bench 15736.0.3 94f57a8a76b3 */
/* bench 15736.0.4 a648702f2896 */
/* bench 15736.0.5 3c5ac75b3b32 */
		reg = <0xf0000fc0 0x40>;
		interrupts = <19>, <31>, <34>, <35>, <52>, <53>, <54>, <55>;
		clocks = <&main_clk>;
	};
