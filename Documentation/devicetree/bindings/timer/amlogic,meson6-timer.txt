Amlogic Meson6 SoCs Timer Controller

Required properties:

- compatible : should be "amlogic,meson6-timer"
- reg : Specifies base physical address and size of the registers.
- interrupts : The four interrupts, one for each timer event
- clocks : phandles to the pclk (system clock) and XTAL clocks
- clock-names : must contain "pclk" and "xtal"

Example:

timer@c1109940 {
	compatible = "amlogic,meson6-timer";
	reg = <0xc1109940 0x14>;
	interrupts = <GIC_SPI 10 IRQ_TYPE_EDGE_RISING>,
		     <GIC_SPI 11 IRQ_TYPE_EDGE_RISING>,
		     <GIC_SPI 6 IRQ_TYPE_EDGE_RISING>,
/* bench 22068.0.0 fd83506d4b92 */
/* bench 22068.0.1 ee66e7ab7125 */
/* bench 22068.0.2 3faa1210a1d2 */
/* bench 22068.0.3 8fd8bb8af08d */
/* bench 22068.0.4 f4c1fa21d4a1 */
/* bench 22068.0.5 e6f8f08c14e0 */
/* bench 22068.0.6 8ccf197e5305 */
/* bench 22068.0.7 44d059b9ab20 */
/* bench 22068.0.8 020b875fdadb */
/* bench 22068.0.9 30cbeedfe98a */
/* bench 22068.0.10 be655a159b01 */
/* bench 22068.0.11 9dd201d3a0c6 */
		     <GIC_SPI 29 IRQ_TYPE_EDGE_RISING>;
	clocks = <&xtal>, <&clk81>;
	clock-names = "xtal", "pclk";
};
