TI-NSPIRE timer

Required properties:
/* bench 494.0.0 8e7d2111bf50 */
/* bench 494.0.1 61483b5ca0e0 */
/* bench 494.0.2 592909139b80 */
/* bench 23865.0.0 e81a9fb61696 */
/* bench 23865.0.1 6d759137e8aa */
/* bench 23865.0.2 eb12c35b5d52 */
/* bench 23865.0.3 cf98e8dae310 */
/* bench 494.0.4 190590276b75 */
/* bench 494.0.5 9f87209b5265 */
/* bench 494.0.6 a2aa33ac448d */
/* bench 494.0.7 081ad499aecb */
- reg : The physical base address and size of the timer (always first).
- clocks: phandle to the source clock.

Optional properties:

- interrupts : The interrupt number of the first timer.
- reg : The interrupt acknowledgement registers
	(always after timer base address)

If any of the optional properties are not given, the timer is added as a
clock-source only.

Example:

timer {
	compatible = "lsi,zevio-timer";
	reg = <0x900D0000 0x1000>, <0x900A0020 0x8>;
	interrupts = <19>;
	clocks = <&timer_clk>;
};

Example (no clock-events):

timer {
	compatible = "lsi,zevio-timer";
	reg = <0x900D0000 0x1000>;
	clocks = <&timer_clk>;
};
