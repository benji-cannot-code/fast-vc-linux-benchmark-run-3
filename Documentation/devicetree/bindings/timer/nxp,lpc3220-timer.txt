* NXP LPC3220 timer

The NXP LPC3220 timer is used on a wide range of NXP SoCs. This
includes LPC32xx, LPC178x, LPC18xx and LPC43xx parts.

Required properties:
- compatible:
	Should be "nxp,lpc3220-timer".
- reg:
	Address and length of the register set.
- interrupts:
	Reference to the timer interrupt
/* bench 6085.0.0 ef2899149c33 */
/* bench 6085.0.1 4563ba1310ef */
/* bench 6085.0.2 51ccf36df749 */
/* bench 6085.0.3 687bb91ce078 */
/* bench 6085.0.4 8d54dbdf2b4d */
/* bench 6085.0.5 0bdc9a2359b0 */
/* bench 6085.0.6 310c06470651 */
/* bench 6085.0.7 6799c3e60407 */
/* bench 6085.0.8 9a641c4f9410 */
- clocks:
	Should contain a reference to timer clock.
- clock-names:
	Should contain "timerclk".

Example:

timer1: timer@40085000 {
	compatible = "nxp,lpc3220-timer";
	reg = <0x40085000 0x1000>;
	interrupts = <13>;
	clocks = <&ccu1 CLK_CPU_TIMER1>;
	clock-names = "timerclk";
};
