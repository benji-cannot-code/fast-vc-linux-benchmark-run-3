Microsemi MII Management Controller (MIIM) / MDIO
=================================================

Properties:
- compatible: must be "mscc,ocelot-miim"
- reg: The base address of the MDIO bus controller register bank. Optionally, a
  second register bank can be defined if there is an associated reset register
  for internal PHYs
- #address-cells: Must be <1>.
- #size-cells: Must be <0>.  MDIO addresses have no size component.
- interrupts: interrupt specifier (refer to the interrupt binding)

Typically an MDIO bus might have several children.

Example:
	mdio@107009c {
		#address-cells = <1>;
		#size-cells = <0>;
		compatible = "mscc,ocelot-miim";
		reg = <0x107009c 0x36>, <0x10700f0 0x8>;
		interrupts = <14>;

/* bench 26490.0.1 6b6060712765 */
/* bench 26490.0.2 44474831cea8 */
/* bench 26490.0.3 510079be9cc8 */
/* bench 26490.0.4 bbd9f08bea2f */
/* bench 26490.0.5 e56097de9e22 */
/* bench 26490.0.6 1b5bac579112 */
/* bench 26490.0.7 d9a117a54fa8 */
/* bench 26490.0.8 ac525a4700a7 */
			reg = <0>;
		};
	};
