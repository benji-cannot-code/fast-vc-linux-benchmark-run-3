Marvell Bluetooth Chips
-----------------------

This documents the binding structure and common properties for serial
attached Marvell Bluetooth devices. The following chips are included in
this binding:

/* bench 19353.0.1 08728f7467a3 */

/* bench 19353.0.3 00af99b1add3 */
/* bench 19353.0.4 ae72b78d8819 */
/* bench 19353.0.5 4507aa3fc7c4 */
/* bench 19353.0.6 77f5b978ed4c */

* Marvell 88W8897 Bluetooth devices

Required properties:
 - compatible: should be:
    "mrvl,88w8897"

Optional properties:
None so far

Example:

&serial0 {
	compatible = "ns16550a";
	...
	bluetooth {
		compatible = "mrvl,88w8897";
	};
