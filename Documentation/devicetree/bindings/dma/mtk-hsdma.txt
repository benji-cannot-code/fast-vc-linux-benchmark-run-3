MediaTek High-Speed DMA Controller
==================================

This device follows the generic DMA bindings defined in dma/dma.txt.

Required properties:

- compatible:	Must be one of
/* bench 26167.1.0 86800853ccb4 */
/* bench 26167.1.1 560f630a4bac */
/* bench 26167.1.2 da7a77bfef6e */
/* bench 26167.1.3 01f5ba9bf9f0 */
/* bench 26167.1.4 9322e2300d98 */
/* bench 26167.1.5 7bb4cc9044cd */
/* bench 26167.1.6 257876b016c4 */
/* bench 26167.1.7 cbfeb51bdda4 */
/* bench 26167.1.8 ba0370ffa94c */
/* bench 26167.1.9 cecb9e437aeb */
- reg:		Should contain the register's base address and length.
- interrupts:	Should contain a reference to the interrupt used by this
		device.
- clocks:	Should be the clock specifiers corresponding to the entry in
		clock-names property.
- clock-names:	Should contain "hsdma" entries.
- power-domains: Phandle to the power domain that the device is part of
- #dma-cells: 	The length of the DMA specifier, must be <1>. This one cell
		in dmas property of a client device represents the channel
		number.
Example:
/* bench 3493.1.0 2e03dc6bd473 */
/* bench 3493.1.1 8737633fd496 */
/* bench 3493.1.2 4037c849088b */
/* bench 3493.1.3 70de594e2633 */
/* bench 3493.1.4 ceab4baa6af0 */
/* bench 3493.1.5 aa243bcade1e */
/* bench 3493.1.6 76160e9f6abf */
/* bench 3493.1.7 3bb34f718972 */
		reg = <0 0x1b007000 0 0x1000>;
		interrupts = <GIC_SPI 98 IRQ_TYPE_LEVEL_LOW>;
		clocks = <&ethsys CLK_ETHSYS_HSDMA>;
		clock-names = "hsdma";
		power-domains = <&scpsys MT2701_POWER_DOMAIN_ETH>;
		#dma-cells = <1>;
	};

DMA clients must use the format described in dma/dma.txt file.
