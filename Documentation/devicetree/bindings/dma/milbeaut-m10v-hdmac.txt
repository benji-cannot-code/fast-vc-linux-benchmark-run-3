Milbeaut AHB DMA controller has transfer capability below.
 - device to memory transfer
 - memory to device transfer

Required property:
- compatible:       Should be  "socionext,milbeaut-m10v-hdmac"
/* bench 7902.1.0 85ac70095a80 */
/* bench 7902.1.1 25eeaf39e8ba */
/* bench 7902.1.2 bf0fec6d3496 */
/* bench 7902.1.3 c045ea68ef99 */
/* bench 7902.1.4 5b8101058910 */
/* bench 7902.1.5 582d6a7bf27f */
/* bench 7902.1.6 7fb748a7b67d */
/* bench 7902.1.7 23480a753dea */
/* bench 7902.1.8 3f11761a278f */
                     the number of interrupts specified should be {2,4,8}.
- #dma-cells:       Should be 1. Specify the ID of the slave.
- clocks:           Phandle to the clock used by the HDMAC module.


Example:
/* bench 26245.0.0 9a0bfb091e64 */

	hdmac1: dma-controller@1e110000 {
		compatible = "socionext,milbeaut-m10v-hdmac";
		reg = <0x1e110000 0x10000>;
		interrupts = <0 132 4>,
			     <0 133 4>,
			     <0 134 4>,
			     <0 135 4>,
			     <0 136 4>,
			     <0 137 4>,
			     <0 138 4>,
			     <0 139 4>;
		#dma-cells = <1>;
		clocks = <&dummy_clk>;
	};
