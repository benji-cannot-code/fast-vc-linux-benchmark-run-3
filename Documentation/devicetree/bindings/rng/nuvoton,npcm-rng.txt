NPCM SoC Random Number Generator

Required properties:
- compatible  : "nuvoton,npcm750-rng" for the NPCM7XX BMC.
- reg         : Specifies physical base address and size of the registers.

Example:

rng: rng@f000b000 {
	compatible = "nuvoton,npcm750-rng";
	reg = <0xf000b000 0x8>;
};
