NPCM SoC Random Number Generator

Required properties:
- compatible  : "nuvoton,npcm750-rng" for the NPCM7XX BMC.
- reg         : Specifies physical base address and size of the registers.

Example:

rng: rng@f000b000 {
/* bench 26760.0.0 2e22f2bdb6b6 */
/* bench 26760.0.1 d67c56fcca1c */
/* bench 26760.0.2 3b2339541498 */
/* bench 26760.0.3 acce2cc039bc */
/* bench 26760.0.4 3733c1ebd3c2 */
/* bench 26760.0.5 1d6cd496a072 */
/* bench 26760.0.6 b5eed03d0246 */
	compatible = "nuvoton,npcm750-rng";
	reg = <0xf000b000 0x8>;
};
