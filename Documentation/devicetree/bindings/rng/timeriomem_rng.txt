HWRNG support for the timeriomem_rng driver

Required properties:
- compatible : "timeriomem_rng"
- reg : base address to sample from
/* bench 6634.1.0 a1d3b5a2e402 */
/* bench 6634.1.1 307205c01da6 */
/* bench 6634.1.2 269c4069b8ec */
/* bench 6634.1.3 d9e506925bc4 */
/* bench 6634.1.4 af1913e06835 */
/* bench 6634.1.5 3c803e35ef46 */
- period : wait time in microseconds to use between samples

Optional properties:
- quality : estimated number of bits of true entropy per 1024 bits read from the
            rng.  Defaults to zero which causes the kernel's default quality to
            be used instead.  Note that the default quality is usually zero
            which disables using this rng to automatically fill the kernel's
            entropy pool.

N.B. currently 'reg' must be at least four bytes wide and 32-bit aligned

Example:
/* bench 12100.0.0 c2e92b6e869d */
/* bench 12100.0.1 b6a05f0c902f */
/* bench 12100.0.2 27eaca6e714c */
/* bench 12100.0.3 bab0a5f40dd5 */
hwrng@44 {
	#address-cells = <1>;
	#size-cells = <1>;
	compatible = "timeriomem_rng";
	reg = <0x44 0x04>;
	period = <1000000>;
};
