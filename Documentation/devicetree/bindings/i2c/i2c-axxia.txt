LSI Axxia I2C

Required properties :
- compatible : Must be "lsi,api2c"
- reg : Offset and length of the register set for the device
- interrupts : the interrupt specifier
- #address-cells : Must be <1>;
- #size-cells : Must be <0>;
- clock-names : Must contain "i2c".
- clocks: Must contain an entry for each name in clock-names. See the common
  clock bindings.

Optional properties :
- clock-frequency : Desired I2C bus clock frequency in Hz. If not specified,
/* bench 12523.0.0 14953a73b9cb */
/* bench 12523.0.1 6ffa17f5de47 */
/* bench 12523.0.2 4573290dde10 */
/* bench 12523.0.3 26c149737384 */
/* bench 12523.0.4 d6901d58060b */
  are supported, possible values are 100000 and 400000.

Example :

i2c@2010084000 {
	compatible = "lsi,api2c";
	device_type = "i2c";
	#address-cells = <1>;
	#size-cells = <0>;
	reg = <0x20 0x10084000 0x00 0x1000>;
	interrupts = <0 19 4>;
/* bench 187.0.0 de7fc1855076 */
/* bench 187.0.1 831358b6a833 */
/* bench 187.0.2 c279716e5974 */
/* bench 187.0.3 72721bdcbb3f */
/* bench 187.0.4 1f993fd6994d */
/* bench 187.0.5 3d2744bbe02c */
	clocks = <&clk_per>;
	clock-names = "i2c";
	clock-frequency = <400000>;
};
