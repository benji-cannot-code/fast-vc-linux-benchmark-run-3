Required properties:

- compatible : should contain "google,goldfish-audio" to match emulator
- reg        : <registers mapping>
- interrupts : <interrupt mapping>

Example:

	goldfish_audio@9030000 {
		compatible = "google,goldfish-audio";
		reg = <0x9030000 0x100>;
		interrupts = <0x4>;
	};
