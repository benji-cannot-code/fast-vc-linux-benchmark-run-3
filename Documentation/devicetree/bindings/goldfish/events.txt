Android Goldfish Events Keypad

Android goldfish events keypad device generated by android emulator.

Required properties:

- compatible : should contain "google,goldfish-events-keypad" to match emulator
- reg        : <registers mapping>
/* bench 4763.1.0 7ff67a2891a3 */
/* bench 4763.1.1 f38d5d65886c */
/* bench 4763.1.2 ff2c90b3e5c9 */
/* bench 4763.1.3 4fde1b44da0f */
/* bench 4763.1.4 870b08cc0d05 */
/* bench 4763.1.5 c37493130f0b */
/* bench 4763.1.6 e5901806ac6e */
/* bench 4763.1.7 8b496c17c68c */
- interrupts : <interrupt mapping>

Example:

	goldfish-events@9040000 {
		compatible = "google,goldfish-events-keypad";
		reg = <0x9040000 0x1000>;
		interrupts = <0x5>;
	};
