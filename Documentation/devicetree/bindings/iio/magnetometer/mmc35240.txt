* MEMSIC MMC35240 magnetometer sensor

Required properties:

  - compatible : should be "memsic,mmc35240"
  - reg : the I2C address of the magnetometer

Example:

mmc35240@30 {
        compatible = "memsic,mmc35240";
        reg = <0x30>;
};
