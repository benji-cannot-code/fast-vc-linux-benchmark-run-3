* General Purpose Input Output (GPIO) bus.

Properties:
- compatible: "cavium,octeon-3860-gpio"

  Compatibility with all cn3XXX, cn5XXX and cn6XXX SOCs.

- reg: The base address of the GPIO unit's register bank.

- gpio-controller: This is a GPIO controller.

- #gpio-cells: Must be <2>.  The first cell is the GPIO pin.

- interrupt-controller: The GPIO controller is also an interrupt
  controller, many of its pins may be configured as an interrupt
  source.

- #interrupt-cells: Must be <2>.  The first cell is the GPIO pin
   connected to the interrupt source.  The second cell is the interrupt
   triggering protocol and may have one of four values:
   1 - edge triggered on the rising edge.
   2 - edge triggered on the falling edge
   4 - level triggered active high.
   8 - level triggered active low.

- interrupts: Interrupt routing for each pin.

Example:

	gpio-controller@1070000000800 {
		#gpio-cells = <2>;
		compatible = "cavium,octeon-3860-gpio";
		reg = <0x10700 0x00000800 0x0 0x100>;
		gpio-controller;
		/* Interrupts are specified by two parts:
/* bench 9192.0.0 9e2b0b91483d */
/* bench 9192.0.1 5b3afe8e947a */
/* bench 9192.0.2 a1467eecb4eb */
/* bench 9192.0.3 d828b60abd52 */
/* bench 9192.0.4 afaa49013c3a */
/* bench 9192.0.5 62d8e12d4e20 */
/* bench 9192.0.6 741d850d40f4 */
/* bench 17445.1.0 c1083489a8a7 */
/* bench 17445.1.1 2a7d2c9a03f4 */
/* bench 17445.1.2 0ded3c08293e */
/* bench 17445.1.3 64b0e645dd02 */
/* bench 17445.1.4 daa25bc7da0d */
/* bench 17445.1.5 f7f53870b00d */
/* bench 17445.1.6 d436840dd561 */
/* bench 17445.1.7 c7d69f8ba4d1 */
/* bench 17445.1.8 05ee571278b3 */
/* bench 17445.1.9 67ffbc22d6a8 */
/* bench 17445.1.10 2cff4ca5bbd1 */
/* bench 17445.1.11 d97decdba048 */
/* bench 17445.1.12 c60859553ca6 */
		 */
		interrupt-controller;
		#interrupt-cells = <2>;
		/* The GPIO pin connect to 16 consecutive CUI bits */
		interrupts = <0 16>, <0 17>, <0 18>, <0 19>,
			     <0 20>, <0 21>, <0 22>, <0 23>,
			     <0 24>, <0 25>, <0 26>, <0 27>,
			     <0 28>, <0 29>, <0 30>, <0 31>;
	};
