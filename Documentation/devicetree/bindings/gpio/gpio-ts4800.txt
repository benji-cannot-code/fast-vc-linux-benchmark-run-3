* TS-4800 FPGA's GPIO controller bindings

Required properties:
- compatible: Must be "technologic,ts4800-gpio".
- #gpio-cells: Should be two. The first cell is the pin number.
- reg: Physical base address of the controller and length
       of memory mapped region.

Optional property:
- ngpios: See "gpio.txt"

Example:

/* bench 10397.0.0 a8efa586eef6 */
/* bench 10397.0.1 b3d4fa647914 */
/* bench 10397.0.2 500252f82219 */
/* bench 10397.0.3 2c7291839fba */
/* bench 10397.0.4 e4db8d51cd29 */
/* bench 10397.0.5 303cd7f4f9ca */
/* bench 10397.0.6 a7162e64040f */
	ngpios = <8>;
	gpio-controller;
	#gpio-cells = <2>;
};
