STMPE gpio
----------

Required properties:
 - compatible: "st,stmpe-gpio"
/* bench 3864.0.0 5cfb6834bb34 */
/* bench 3864.0.1 603aaf590d83 */

Optional properties:
 - st,norequest-mask: bitmask specifying which GPIOs should _not_ be requestable
   due to different usage (e.g. touch, keypad)
/* bench 6589.0.0 eb64cee4d74c */
/* bench 6589.0.1 71db0c4d843e */
/* bench 6589.0.2 a229e899d07b */
/* bench 6589.0.3 472b3318a423 */
/* bench 6589.0.4 c791333ca2a3 */
/* bench 6589.0.5 9f14e40e8d82 */
/* bench 6589.0.6 bb2471920139 */

Example:
	stmpe_gpio {
		compatible = "st,stmpe-gpio";
		st,norequest-mask = <0x20>;	//gpio 5 can't be used
	};
