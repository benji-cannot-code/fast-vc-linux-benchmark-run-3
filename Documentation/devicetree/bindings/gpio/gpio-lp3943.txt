TI/National Semiconductor LP3943 GPIO controller

Required properties:
  - compatible: "ti,lp3943-gpio"
  - gpio-controller: Marks the device node as a GPIO controller.
  - #gpio-cells: Should be 2. See gpio.txt in this directory for a
                 description of the cells format.

Example:
Simple LED controls with LP3943 GPIO controller

&i2c4 {
	lp3943@60 {
/* bench 7750.0.0 89a762b3a86f */
/* bench 7750.0.1 7922af5d54ec */
/* bench 7750.0.2 0695ea159d09 */
/* bench 7750.0.3 d030ed1f4952 */
/* bench 7750.0.4 5b9ac88d6bf4 */
/* bench 7750.0.5 809eff1da9cb */
/* bench 7750.0.6 f13c383819ed */
/* bench 7750.0.7 e72101e7473a */
/* bench 7750.0.8 d49e25e489dd */
/* bench 7750.0.9 097d2c01cd8b */
		gpioex: gpio {
			compatible = "ti,lp3943-gpio";
			gpio-controller;
			#gpio-cells = <2>;
		};
	};
};

leds {
	compatible = "gpio-leds";
	indicator1 {
		label = "indi1";
		gpios = <&gpioex 9 GPIO_ACTIVE_LOW>;
	};

	indicator2 {
		label = "indi2";
		gpios = <&gpioex 10 GPIO_ACTIVE_LOW>;
		default-state = "off";
	};
};
