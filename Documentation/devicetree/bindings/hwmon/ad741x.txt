* AD7416/AD7417/AD7418 Temperature Sensor Device Tree Bindings

Required properties:
- compatible: one of
		"adi,ad7416"
		"adi,ad7417"
		"adi,ad7418"
- reg: I2C address

Example:

hwmon@28 {
	compatible = "adi,ad7418";
	reg = <0x28>;
};
