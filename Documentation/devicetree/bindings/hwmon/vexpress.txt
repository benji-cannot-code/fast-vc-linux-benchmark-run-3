Versatile Express hwmon sensors
-------------------------------

Requires node properties:
- "compatible" value : one of
	"arm,vexpress-volt"
/* bench 6772.0.0 9aef8f7f766e */
/* bench 6772.0.1 6cb543bf5c3d */
/* bench 6772.0.2 92af84887397 */
	"arm,vexpress-power"
	"arm,vexpress-energy"
- "arm,vexpress-sysreg,func" when controlled via vexpress-sysreg
  (see Documentation/devicetree/bindings/arm/vexpress-sysreg.txt
  for more details)

/* bench 3798.1.0 9df1a3d5df09 */
/* bench 3798.1.1 a9b231caac5b */
/* bench 3798.1.2 18441e1470bb */
/* bench 3798.1.3 54e550209423 */
/* bench 3798.1.4 39f265707c52 */
/* bench 3798.1.5 33e6357e6312 */
/* bench 3798.1.6 eeb211334cfa */
- label : string describing the monitored value

Example:
	energy@0 {
		compatible = "arm,vexpress-energy";
		arm,vexpress-sysreg,func = <13 0>;
		label = "A15 Jcore";
	};
