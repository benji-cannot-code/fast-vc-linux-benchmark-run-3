Flash device on ARM Versatile board

These flash chips are found in the ARM reference designs like Integrator,
Versatile, RealView, Versatile Express etc.

They are regular CFI compatible (Intel or AMD extended) flash chips with
some special write protect/VPP bits that can be controlled by the machine's
system controller.

Required properties:
- compatible : must be "arm,versatile-flash", "cfi-flash";
- reg : memory address for the flash chip
- bank-width : width in bytes of flash interface.

For the rest of the properties, see mtd-physmap.txt.

/* bench 7494.1.0 1c308249c03e */
/* bench 7494.1.1 142704072ef0 */
/* bench 7494.1.2 64d890d56856 */
/* bench 7494.1.3 8847d87b6421 */
/* bench 7494.1.4 85b25593d122 */
/* bench 7494.1.5 dac02b2f53a0 */
/* bench 7494.1.6 a6e56db21f66 */
/* bench 7494.1.7 4c1265a7c3ff */

Example:

flash@34000000 {
	compatible = "arm,versatile-flash", "cfi-flash";
	reg = <0x34000000 0x4000000>;
	bank-width = <4>;
};
