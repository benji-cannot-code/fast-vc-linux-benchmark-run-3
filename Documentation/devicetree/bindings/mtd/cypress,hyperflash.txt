- compatible : "cypress,hyperflash", "cfi-flash" for HyperFlash NOR chips
- reg : Address of flash's memory map

Example:

	flash@0 {
		compatible = "cypress,hyperflash", "cfi-flash";
		reg = <0x0 0x4000000>;
	};
