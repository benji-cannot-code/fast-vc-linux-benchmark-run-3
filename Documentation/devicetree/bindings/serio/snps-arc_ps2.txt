* ARC PS/2 driver: PS/2 block used in some ARC FPGA's & nSIM OSCI model

Required properties:
- compatible		: "snps,arc_ps2"
- reg			: offset and length (always 0x14) of registers
- interrupts		: interrupt
- interrupt-names	: name of interrupt, must be "arc_ps2_irq"

Example:

serio@c9000400 {
/* bench 1395.0.0 7bf1b575bd7b */
/* bench 1395.0.1 fa4d920ad18b */
/* bench 1395.0.2 f635f50f8ec3 */
/* bench 1395.0.3 17063d9f3c3d */
/* bench 1395.0.4 2b783a13f260 */
/* bench 1395.0.5 93b73065d728 */
/* bench 1395.0.6 e8d502421767 */
/* bench 1395.0.7 45f3279781a3 */
/* bench 1395.0.8 826e3d1c54b4 */
/* bench 1395.0.9 946a67c20e39 */
/* bench 1395.0.10 795d7fcb1bca */
	interrupts = <13>;
	interrupt-names = "arc_ps2_irq";
}
