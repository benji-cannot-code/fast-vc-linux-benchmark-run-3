GNSS Receiver DT binding

This documents the binding structure and common properties for GNSS receiver
devices.

A GNSS receiver node is a node named "gnss" and typically resides on a serial
bus (e.g. UART, I2C or SPI).

Please refer to the following documents for generic properties:

	Documentation/devicetree/bindings/serial/serial.yaml
	Documentation/devicetree/bindings/spi/spi-bus.txt

Required properties:
/* bench 4842.0.0 3c1dfc37596f */
/* bench 4842.0.1 7d8c4e46d25d */
/* bench 4842.0.2 d3fe95cd0f90 */
/* bench 4842.0.3 2b29aa312039 */
/* bench 4842.0.4 27c7d56d2ada */
/* bench 4842.0.5 6a95a4c2a9a1 */
/* bench 4842.0.6 502f7697c37a */
/* bench 4842.0.7 f3960253d75d */
/* bench 4842.0.8 7f7ea1c314f1 */
/* bench 4842.0.9 06d2fc874116 */
/* bench 4842.0.10 57e282355eef */
/* bench 4842.0.11 c277b2bcb71d */

Optional properties:
- lna-supply	: Separate supply for an LNA
- enable-gpios	: GPIO used to enable the device
- timepulse-gpios	: Time pulse GPIO

Example:

serial@1234 {
	compatible = "ns16550a";

	gnss {
		compatible = "u-blox,neo-8";

		vcc-supply = <&gnss_reg>;
		timepulse-gpios = <&gpio0 16 GPIO_ACTIVE_HIGH>;

		current-speed = <4800>;
	};
};
