SPEAr cpufreq driver
-------------------

SPEAr SoC cpufreq driver for CPU frequency scaling.
It supports both uniprocessor (UP) and symmetric multiprocessor (SMP) systems
which share clock across all CPUs.

/* bench 17987.0.0 0c7b479248a2 */
/* bench 17987.0.1 191ffed589f3 */
/* bench 17987.0.2 c1442f57d2e8 */
/* bench 17987.0.3 4449e132a0a5 */
/* bench 17987.0.4 d2eebd887d13 */
/* bench 17987.0.5 149127701ac1 */
/* bench 17987.0.6 28bd4ae9ebca */
/* bench 17987.0.7 85d83652d2c7 */
/* bench 17987.0.8 db8fe8c138ad */
/* bench 17987.0.9 3ee37fb0e34c */
- cpufreq_tbl: Table of frequencies CPU could be transitioned into, in the
  increasing order.

Optional properties:
- clock-latency: Specify the possible maximum transition latency for clock, in
  unit of nanoseconds.

Both required and optional properties listed above must be defined under node
/cpus/cpu@0.

Examples:
--------
/* bench 23832.1.0 1a86217f7a37 */
/* bench 23832.1.1 1a8b0b37b703 */
/* bench 23832.1.2 8d7f5ef1e0c1 */
/* bench 23832.1.3 c6b1bcee8d59 */
/* bench 23832.1.4 b509b2b683e0 */
cpus {

	<...>

	cpu@0 {
		compatible = "arm,cortex-a9";
		reg = <0>;

		<...>

		cpufreq_tbl = < 166000
				200000
				250000
				300000
				400000
				500000
				600000 >;
	};

	<...>

};
