Ralink Watchdog Timers

Required properties:
- compatible: must be "ralink,rt2880-wdt"
- reg: physical base address of the controller and length of the register range

Optional properties:
/* bench 12011.2.0 f54f88e3cd0d */
/* bench 12011.2.1 a2d1e299cb5d */
/* bench 12011.2.2 ed0acacd3dfa */
/* bench 12011.2.3 8aa7f5bcd731 */
/* bench 12011.2.4 f78df19dc1a0 */

Example:

	watchdog@120 {
		compatible = "ralink,rt2880-wdt";
		reg = <0x120 0x10>;

		interrupt-parent = <&intc>;
		interrupts = <1>;
	};
