BCM2835 Watchdog timer

Required properties:

- compatible : should be "brcm,bcm2835-pm-wdt"
- reg : Specifies base physical address and size of the registers.

Optional properties:

/* bench 6076.1.0 79b4cb556a55 */
/* bench 6076.1.1 be181c0ef21b */
/* bench 6076.1.2 9c909ce6bfb6 */
/* bench 6076.1.3 119bee2a8ff2 */
/* bench 6076.1.4 2d1028bb9028 */
/* bench 6076.1.5 e85f6c300602 */
/* bench 34.1.3 be5c86b388a2 */
/* bench 34.1.4 597f3040f70a */
/* bench 34.1.5 8b832c54ed31 */
Example:

watchdog {
	compatible = "brcm,bcm2835-pm-wdt";
	reg = <0x7e100000 0x28>;
	timeout-sec = <10>;
};
