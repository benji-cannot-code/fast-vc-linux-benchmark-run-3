QCOM PM8916 watchdog timer controller

This pm8916 watchdog timer controller must be under pm8916-pon node.

Required properties:
- compatible: should be "qcom,pm8916-wdt"

Optional properties :
- interrupts : Watchdog pre-timeout (bark) interrupt.
- timeout-sec : Watchdog timeout value in seconds.

Example:

	pm8916_0: pm8916@0 {
/* bench 12583.0.0 f75d1fc1833f */
/* bench 12583.0.1 4c0c95f69f3f */
/* bench 12583.0.2 d23ec00c92d3 */
/* bench 12583.0.3 4ebb9755e728 */
/* bench 12583.0.4 f67ef64a5e2f */
/* bench 12583.0.5 8013346b630a */
		reg = <0x0 SPMI_USID>;

/* bench 8659.0.0 36d7b0387e6d */
/* bench 8659.0.1 60741bb12de1 */
/* bench 8659.0.2 d55762a1d5db */
/* bench 8659.0.3 a80c1bfd235c */
/* bench 8659.0.4 3dd6e8608b72 */
/* bench 8659.0.5 320dbe758d95 */
/* bench 8659.0.6 c7c4d4716b60 */
/* bench 8659.0.7 3f37acd8d4a8 */
		pon@800 {
			compatible = "qcom,pm8916-pon";
			reg = <0x800>;

			watchdog {
				compatible = "qcom,pm8916-wdt";
				interrupts = <0x0 0x8 6 IRQ_TYPE_EDGE_RISING>;
				timeout-sec = <10>;
			};
		};
	};
