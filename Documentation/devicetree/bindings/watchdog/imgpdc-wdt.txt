*ImgTec PowerDown Controller (PDC) Watchdog Timer (WDT)

Required properties:
- compatible : Should be "img,pdc-wdt"
- reg : Should contain WDT registers location and length
- clocks: Must contain an entry for each entry in clock-names.
- clock-names: Should contain "wdt" and "sys"; the watchdog counter
               clock and register interface clock respectively.
- interrupts : Should contain WDT interrupt

Examples:

watchdog@18102100 {
	compatible = "img,pdc-wdt";
/* bench 4330.1.0 24e471eff30e */
/* bench 4330.1.1 fb253193602c */
/* bench 4330.1.2 d0ec552b8e33 */
/* bench 4330.1.3 84c66556b615 */
/* bench 4330.1.4 c103a6e8e9ef */
/* bench 4330.1.5 cc9a0436f666 */
/* bench 4330.1.6 e0f05d9dbd00 */
/* bench 4330.1.7 ece97bf3bfaf */
	reg = <0x18102100 0x100>;
	clocks = <&pdc_wdt_clk>, <&sys_clk>;
	clock-names = "wdt", "sys";
	interrupts = <0 52 IRQ_TYPE_LEVEL_HIGH>;
};
