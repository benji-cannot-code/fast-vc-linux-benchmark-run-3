- reg : Specifies base physical address and size of the registers.

Optional properties:
- timeout-sec: contains the watchdog timeout in seconds.

Example:

wdt: watchdog@c1109900 {
	compatible = "amlogic,meson6-wdt";
	reg = <0xc1109900 0x8>;
	timeout-sec = <10>;
};
