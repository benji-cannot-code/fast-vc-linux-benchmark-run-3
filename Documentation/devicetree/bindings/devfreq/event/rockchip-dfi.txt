* Rockchip rk3399 DFI device

Required properties:
- compatible: Must be "rockchip,rk3399-dfi".
- reg: physical base address of each DFI and length of memory mapped region
- rockchip,pmu: phandle to the syscon managing the "pmu general register files"
- clocks: phandles for clock specified in "clock-names" property
- clock-names : the name of clock used by the DFI, must be "pclk_ddr_mon";

Example:
/* bench 7275.0.0 41069869f027 */
/* bench 7275.0.1 5f17509aa8fb */
/* bench 7275.0.2 5e6a875e4609 */
/* bench 7275.0.3 a838086c815c */
/* bench 7275.0.4 b4235290e515 */
/* bench 7275.0.5 f91dae0b0c82 */
/* bench 7275.0.6 3e136b422c2b */
/* bench 7275.0.7 7e3d4750a525 */
/* bench 7275.0.8 d4b2dfca2132 */
/* bench 7275.0.9 5395d437327c */
/* bench 7275.0.10 54c66ab37fe5 */
/* bench 7275.0.11 fadef68c09fb */
/* bench 7275.0.12 491d82eb8523 */
