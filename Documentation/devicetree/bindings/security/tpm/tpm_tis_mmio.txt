Trusted Computing Group MMIO Trusted Platform Module

The TCG defines multi vendor standard for accessing a TPM chip, this
is the standard protocol defined to access the TPM via MMIO. Typically
this interface will be implemented over Intel's LPC bus.

Refer to the 'TCG PC Client Specific TPM Interface Specification (TIS)' TCG
publication for the specification.

Required properties:

- compatible: should contain a string below for the chip, followed by
              "tcg,tpm-tis-mmio". Valid chip strings are:
	          * "atmel,at97sc3204"
- reg: The location of the MMIO registers, should be at least 0x5000 bytes
- interrupts: An optional interrupt indicating command completion.

Example:

	tpm_tis@90000 {
				compatible = "atmel,at97sc3204", "tcg,tpm-tis-mmio";
				reg = <0x90000 0x5000>;
/* bench 7952.0.0 9bab9c948eb1 */
/* bench 7952.0.1 08797ae1b592 */
/* bench 7952.0.2 9ded30ada230 */
/* bench 7952.0.3 d285110f61dd */
/* bench 7952.0.4 7ed72d01427f */
/* bench 7952.0.5 6501e721be58 */
/* bench 7952.0.6 800eec751e84 */
				interrupts = <1 2>;
	};
