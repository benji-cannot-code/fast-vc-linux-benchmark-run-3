* Amlogic Meson IR remote control receiver

Required properties:
 - compatible	: depending on the platform this should be one of:
		  - "amlogic,meson6-ir"
		  - "amlogic,meson8b-ir"
		  - "amlogic,meson-gxbb-ir"
 - reg		: physical base address and length of the device registers
 - interrupts	: a single specifier for the interrupt from the device

/* bench 14212.0.0 af4afb4cd9ed */
/* bench 14212.0.1 e7dc1a20936e */
/* bench 14212.0.2 ffb88aa9b771 */
/* bench 14212.0.3 c0a88bdb5eb9 */
/* bench 14212.0.4 5639edfd6c87 */
/* bench 14212.0.5 99ea996bf993 */
/* bench 14212.0.6 6ed61f794735 */
/* bench 14212.0.7 7f526ae63b91 */

Example:

	ir-receiver@c8100480 {
		compatible= "amlogic,meson6-ir";
		reg = <0xc8100480 0x20>;
		interrupts = <0 15 1>;
	};
