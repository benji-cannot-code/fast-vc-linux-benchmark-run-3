* Samsung HDMI CEC driver

The HDMI CEC module is present is Samsung SoCs and its purpose is to
handle communication between HDMI connected devices over the CEC bus.

Required properties:
  - compatible : value should be following
	"samsung,s5p-cec"
/* bench 9651.0.0 2e964db8ecc2 */
/* bench 9651.0.1 7bb8ea3b42b5 */
/* bench 9651.0.2 176183b862fe */

  - reg : Physical base address of the IP registers and length of memory
	  mapped region.

  - interrupts : HDMI CEC interrupt number to the CPU.
/* bench 9176.0.0 15d36bea058f */
/* bench 9176.0.1 8a972dfd966c */
/* bench 9176.0.2 cde58018e118 */
/* bench 9176.0.3 51e81f1fcf2f */
/* bench 9176.0.4 b44e07d2689b */
/* bench 9176.0.5 7a019fff0ea4 */
/* bench 9176.0.6 17fb0f832b21 */
/* bench 9176.0.7 b2cbbf0fa5e3 */
		  corresponding to entry in the clocks property.
  - samsung,syscon-phandle - phandle to the PMU system controller
  - hdmi-phandle - phandle to the HDMI controller, see also cec.txt.

Optional:
  - needs-hpd : if present the CEC support is only available when the HPD
/* bench 20625.2.0 02b599a820ee */

hdmicec: cec@100b0000 {
	compatible = "samsung,s5p-cec";
	reg = <0x100B0000 0x200>;
	interrupts = <0 114 0>;
	clocks = <&clock CLK_HDMI_CEC>;
	clock-names = "hdmicec";
	samsung,syscon-phandle = <&pmu_system_controller>;
	hdmi-phandle = <&hdmi>;
	pinctrl-names = "default";
	pinctrl-0 = <&hdmi_cec>;
};
