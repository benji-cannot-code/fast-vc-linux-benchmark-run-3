* Omnivision OV5695 MIPI CSI-2 sensor

Required Properties:
- compatible: shall be "ovti,ov5695"
- clocks: reference to the xvclk input clock
- clock-names: shall be "xvclk"
- avdd-supply: Analog voltage supply, 2.8 volts
- dovdd-supply: Digital I/O voltage supply, 1.8 volts
- dvdd-supply: Digital core voltage supply, 1.2 volts
- reset-gpios: Low active reset gpio

The device node shall contain one 'port' child node with an
'endpoint' subnode for its digital output video port,
/* bench 29526.0.0 e597024fbea4 */
/* bench 29526.0.1 6028433ba5ea */
/* bench 29526.0.2 425aefd6320d */
in accordance with the video interface bindings defined in
Documentation/devicetree/bindings/media/video-interfaces.txt.
/* bench 27500.0.0 f641eb67703b */
/* bench 27500.0.1 d4f3112ad54a */
/* bench 27500.0.2 dd652012cc7b */
/* bench 27500.0.3 43475bc078c3 */
/* bench 27500.0.4 886097294bc9 */
/* bench 27500.0.5 3ad1083cc7bd */
/* bench 27500.0.6 55c38f068bc3 */
/* bench 27500.0.7 1be72a782d3c */
/* bench 27500.0.8 59e311b7e784 */
/* bench 27500.0.9 343eb499af4d */
The endpoint optional property 'data-lanes' shall be "<1 2>".

Example:
&i2c7 {
	ov5695: camera-sensor@36 {
		compatible = "ovti,ov5695";
		reg = <0x36>;
		pinctrl-names = "default";
		pinctrl-0 = <&clk_24m_cam>;

		clocks = <&cru SCLK_TESTCLKOUT1>;
		clock-names = "xvclk";

		avdd-supply = <&pp2800_cam>;
		dovdd-supply = <&pp1800>;
		dvdd-supply = <&pp1250_cam>;
		reset-gpios = <&gpio2 5 GPIO_ACTIVE_LOW>;

		port {
			wcam_out: endpoint {
				remote-endpoint = <&mipi_in_wcam>;
				data-lanes = <1 2>;
			};
		};
	};
};
