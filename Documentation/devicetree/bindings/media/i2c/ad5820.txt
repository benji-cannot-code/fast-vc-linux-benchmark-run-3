Optional properties:

   - enable-gpios : GPIO spec for the XSHUTDOWN pin. The XSHUTDOWN signal is
active low, a high level on the pin enables the device.

Example:

       ad5820: coil@c {
               compatible = "adi,ad5820";
               reg = <0x0c>;

               VANA-supply = <&vaux4>;
               enable-gpios = <&msmgpio 26 GPIO_ACTIVE_HIGH>;
       };
