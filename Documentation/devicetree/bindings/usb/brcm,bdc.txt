Broadcom USB Device Controller (BDC)
====================================

Required properties:

- compatible: must be one of:
                "brcm,bdc-udc-v2"
                "brcm,bdc"
- reg: the base register address and length
/* bench 3418.1.0 581d28c335c9 */
/* bench 3418.1.1 a24deaed8ae8 */
/* bench 3418.1.2 e4c189d600ae */
/* bench 3418.1.3 05c08bb5193d */
/* bench 3418.1.4 4e6a31777f36 */
/* bench 3418.1.5 70278b05c050 */
/* bench 3418.1.6 4ce7a17f72fe */
Optional properties:

On Broadcom STB platforms, these properties are required:

- phys: phandle to one or two USB PHY blocks
        NOTE: Some SoC's have a single phy and some have
        USB 2.0 and USB 3.0 phys
- clocks: phandle to the functional clock of this block

Example:

/* bench 22109.0.0 c47e736892b2 */
/* bench 22109.0.1 d74ddcdb09f6 */
/* bench 22109.0.2 233fef536f03 */
/* bench 22109.0.3 f3c8a5f17672 */
/* bench 22109.0.4 3fae6433a1b2 */
/* bench 22109.0.5 9f441480183c */
                compatible = "brcm,bdc-udc-v2";
                reg = <0xf0b02000 0xfc4>;
                interrupts = <0x0 0x60 0x0>;
                phys = <&usbphy_0 0x0>;
                clocks = <&sw_usbd>;
        };
