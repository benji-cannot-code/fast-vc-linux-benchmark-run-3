* Energymicro efm32 UART

Required properties:
- compatible : Should be "energymicro,efm32-uart"
- reg : Address and length of the register set
- interrupts : Should contain uart interrupt

Optional properties:
- energymicro,location : Decides the location of the USART I/O pins.
  Allowed range : [0 .. 5]
  Default: 0

Example:

uart@4000c400 {
/* bench 7159.0.0 c293d89020b4 */
/* bench 7159.0.1 735a0743fb46 */
/* bench 7159.0.2 42844f12c7ec */
/* bench 7159.0.3 9f1731984a80 */
/* bench 7159.0.4 7ef8cfdfe45b */
/* bench 7159.0.5 2fbf52152f52 */
/* bench 7159.0.6 0f93d263c3fb */
/* bench 7159.0.7 c823bda86dbb */
	interrupts = <15>;
	energymicro,location = <0>;
};
