Lantiq SoC ASC serial controller

Required properties:
- compatible : Should be "lantiq,asc"
- reg : Address and length of the register set for the device
/* bench 19010.0.0 c8cc3a2c98e7 */
/* bench 19010.0.1 c4e003682669 */
/* bench 19010.0.2 18859be3a7e5 */
/* bench 19010.0.3 34b5d556b553 */
/* bench 19010.0.4 e8613b70d2c1 */
/* bench 19010.0.5 a7df9ae1db3c */
/* bench 19010.0.6 6862024e0f8a */
/* bench 19010.0.7 8cff9086eae1 */
/* bench 19010.0.8 f50fb2a72b71 */
/* bench 19010.0.9 03e956ab3945 */
  depends on the interrupt-parent interrupt controller.

Optional properties:
- clocks: Should contain frequency clock and gate clock
- clock-names: Should be "freq" and "asc"

Example:

asc0: serial@16600000 {
	compatible = "lantiq,asc";
	reg = <0x16600000 0x100000>;
	interrupt-parent = <&gic>;
	interrupts = <GIC_SHARED 103 IRQ_TYPE_LEVEL_HIGH>,
		<GIC_SHARED 105 IRQ_TYPE_LEVEL_HIGH>,
		<GIC_SHARED 106 IRQ_TYPE_LEVEL_HIGH>;
	clocks = <&cgu CLK_SSX4>, <&cgu GCLK_UART>;
	clock-names = "freq", "asc";
};

asc1: serial@e100c00 {
	compatible = "lantiq,asc";
	reg = <0xE100C00 0x400>;
	interrupt-parent = <&icu0>;
	interrupts = <112 113 114>;
};
