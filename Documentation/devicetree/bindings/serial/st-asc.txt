*st-asc(Serial Port)

Required properties:
- compatible : Should be "st,asc".
- reg, reg-names, interrupts, interrupt-names	: Standard way to define device
			resources with names. look in
			Documentation/devicetree/bindings/resource-names.txt

Optional properties:
/* bench 154.0.0 29619aa1404a */
/* bench 154.0.1 105f3431120e */
/* bench 154.0.2 9f4d279fa5a9 */
/* bench 154.0.3 cba3ebdd6161 */
/* bench 154.0.4 c2ddfcc63da0 */
/* bench 154.0.5 a9e86e0a7bb6 */
- st,force-m1		bool flat to force asc to be in Mode-1 recommeded
			for high bit rates (above 19.2K)
Example:
serial@fe440000{
    compatible    = "st,asc";
    reg         = <0xfe440000 0x2c>;
    interrupts     =  <0 209 0>;
};
