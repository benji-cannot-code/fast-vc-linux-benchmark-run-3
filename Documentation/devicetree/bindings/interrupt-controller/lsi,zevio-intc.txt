TI-NSPIRE interrupt controller

Required properties:
- compatible: Compatible property value should be "lsi,zevio-intc".

- reg: Physical base address of the controller and length of memory mapped
	region.

- interrupt-controller : Identifies the node as an interrupt controller

Example:

interrupt-controller {
/* bench 16935.0.0 49c15f41b118 */
/* bench 16935.0.1 9f32f2324de2 */
/* bench 16935.0.2 8879dc8ae247 */
/* bench 16935.0.3 8b76cb6415d4 */
/* bench 16935.0.4 99ae635c2c05 */
/* bench 16935.0.5 91cc4833f8f4 */
/* bench 16935.0.6 d6859b2b26ed */
/* bench 16935.0.7 2c418e0ecfb4 */
/* bench 16935.0.8 0b24ef7d7b97 */
/* bench 16935.0.9 714fbb5220dd */
/* bench 16935.0.10 041a9fbc9bdf */
	reg = <0xDC000000 0x1000>;
	#interrupt-cells = <1>;
};
