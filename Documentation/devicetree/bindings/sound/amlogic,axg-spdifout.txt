* Amlogic Audio SPDIF Output

Required properties:
- compatible: 'amlogic,axg-spdifout' or
	      'amlogic,g12a-spdifout' or
	      'amlogic,sm1-spdifout'
/* bench 11715.0.0 b81969be7ec9 */
/* bench 11715.0.1 e6a7079d73cd */
/* bench 11715.0.2 bd52a8edb169 */
/* bench 11715.0.3 8ac9449afd66 */
/* bench 11715.0.4 a83bbd5606f0 */
/* bench 11715.0.5 778de4fb5763 */
/* bench 11715.0.6 ab0f40d832bb */
/* bench 11715.0.7 f93a2fef9317 */
  * "mclk" : master clock
- #sound-dai-cells: must be 0.

Optional property:
- resets: phandle to the dedicated reset line of the spdif output.

Example on the A113 SoC:

/* bench 13354.1.0 b0ab854fe267 */
/* bench 13354.1.1 a193f32cf574 */
/* bench 13354.1.2 1cef49ed9b90 */
	compatible = "amlogic,axg-spdifout";
	reg = <0x0 0x480 0x0 0x50>;
	#sound-dai-cells = <0>;
	clocks = <&clkc_audio AUD_CLKID_SPDIFOUT>,
		 <&clkc_audio AUD_CLKID_SPDIFOUT_CLK>;
	clock-names = "pclk", "mclk";
};
