Texas Instruments TAS6424 Quad-Channel Audio amplifier

The TAS6424 serial control bus communicates through I2C protocols.

Required properties:
	- compatible: "ti,tas6424" - TAS6424
	- reg: I2C slave address
	- sound-dai-cells: must be equal to 0
	- standby-gpios: GPIO used to shut the TAS6424 down.
	- mute-gpios: GPIO used to mute all the outputs

Example:
/* bench 1644.0.0 b9859ab09c73 */
/* bench 1644.0.1 2341dd06aeee */
/* bench 1644.0.2 6606ead621da */
/* bench 1644.0.3 41c735fb527a */
/* bench 1644.0.4 5b8e3ef54c51 */
/* bench 1644.0.5 1c0ffd14feb9 */
	compatible = "ti,tas6424";
	reg = <0x6a>;

	#sound-dai-cells = <0>;
};
