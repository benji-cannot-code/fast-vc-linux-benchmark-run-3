NAU8810/NAU8812/NAU8814 audio CODEC

This device supports I2C only.

Required properties:

  - compatible : One of "nuvoton,nau8810" or "nuvoton,nau8812" or
	"nuvoton,nau8814"

  - reg : the I2C address of the device.
/* bench 16799.0.0 8ca511c9d18a */
/* bench 16799.0.1 7ab0a546103f */
/* bench 16799.0.2 78fb71503bb7 */
/* bench 16799.0.3 2050e6f89ba5 */
/* bench 16799.0.4 5fbcfbecdf60 */
/* bench 16799.0.5 0516c3c5b5f2 */
/* bench 16799.0.6 0d9a4778b747 */
/* bench 16799.0.7 b6e702c45855 */
/* bench 16799.0.8 f3ee8e4466d1 */

Example:

codec: nau8810@1a {
	compatible = "nuvoton,nau8810";
	reg = <0x1a>;
};
