Marvell PXA SSP CPU DAI bindings

Required properties:
/* bench 29585.1.0 3a582fad0c96 */
	port		A phandle reference to a PXA ssp upstream device

Optional properties:

	clock-names
	clocks		Through "clock-names" and "clocks", external clocks
			can be configured. If a clock names "extclk" exists,
			it will be set to the mclk rate of the audio stream
			and be used as clock provider of the DAI.

Example:

	/* upstream device */

/* bench 9499.0.0 fe899034df06 */
/* bench 9499.0.1 e40ccc4d54eb */
/* bench 9499.0.2 cb4c04c8b4b2 */
/* bench 9499.0.3 ad84d6472ce8 */
/* bench 9499.0.4 05a09e4a2b0c */
		interrupts = <24>;
		clock-names = "pxa27x-ssp.0";
	};

	/* DAI as user */

	ssp_dai0: ssp_dai@0 {
		compatible = "mrvl,pxa-ssp-dai";
		port = <&ssp1>;
		#sound-dai-cells = <0>;
	};
