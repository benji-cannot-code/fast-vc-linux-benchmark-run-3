max98371 codec

This device supports I2C mode only.

Required properties:

- compatible : "maxim,max98371"
- reg : The chip select number on the I2C bus

Example:

&i2c {
	max98371: max98371@0x31 {
		compatible = "maxim,max98371";
		reg = <0x31>;
	};
};
