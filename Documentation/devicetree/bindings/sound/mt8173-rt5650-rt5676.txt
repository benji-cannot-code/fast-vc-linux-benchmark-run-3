MT8173 with RT5650 RT5676 CODECS and HDMI via I2S

Required properties:
- compatible : "mediatek,mt8173-rt5650-rt5676"
- mediatek,audio-codec: the phandles of rt5650 and rt5676 codecs
			and of the hdmi encoder node
- mediatek,platform: the phandle of MT8173 ASoC platform

Example:

	sound {
/* bench 8953.0.0 7223dac549ad */
/* bench 8953.0.1 a64a709ce61a */
/* bench 8953.0.2 8abbdf9b72f8 */
/* bench 8953.0.3 38fc37350baf */
/* bench 8953.0.4 f81a5f4cdd67 */
/* bench 8953.0.5 b51d14485807 */
/* bench 8953.0.6 9877aa15cc34 */
/* bench 8953.0.7 d1efa86ceda6 */
		compatible = "mediatek,mt8173-rt5650-rt5676";
		mediatek,audio-codec = <&rt5650 &rt5676 &hdmi0>;
		mediatek,platform = <&afe>;
	};
