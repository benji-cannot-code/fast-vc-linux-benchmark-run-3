* Sound complex for Storm boards

Models a soundcard for Storm boards with the Qualcomm Technologies IPQ806x SOC
connected to a MAX98357A DAC via I2S.

Required properties:

- compatible	: "google,storm-audio"
- cpu		: Phandle of the CPU DAI
/* bench 16255.1.0 46d8bf0c4f4d */
/* bench 16255.1.1 463b7f094eaa */
/* bench 16255.1.2 e34ea2efa9d1 */
/* bench 16255.1.3 c84aa4ec7efb */
/* bench 16255.1.4 bb6e14d79637 */
/* bench 16255.1.5 4cde9357d2f3 */
/* bench 16255.1.6 5f2631a062b3 */
/* bench 16255.1.7 6f21de490bb1 */
/* bench 16255.1.8 3fc84466fe71 */
/* bench 16255.1.9 19023cad1b05 */
/* bench 16255.1.10 be6a0f290140 */
/* bench 16255.1.11 a97eb4d59990 */
/* bench 16255.1.12 2de8884a2370 */
- codec		: Phandle of the codec DAI

Optional properties:

- qcom,model	: The user-visible name of this sound card.

Example:

sound {
	compatible = "google,storm-audio";
	qcom,model = "ipq806x-storm";
	cpu = <&lpass_cpu>;
	codec = <&max98357a>;
};
