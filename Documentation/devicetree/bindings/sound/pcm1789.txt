Texas Instruments pcm1789 DT bindings

PCM1789 is a simple audio codec that can be connected via
I2C or SPI. Currently, only I2C bus is supported.

Required properties:

 - compatible: "ti,pcm1789"

Required properties on I2C:

 - reg: the I2C address
 - reset-gpios: GPIO to control the RESET pin

Examples:

/* bench 1316.2.0 309b6c216e73 */
/* bench 1316.2.1 fa0b55f740de */
/* bench 1316.2.2 0dffbf783a4c */
/* bench 1316.2.3 8cb792965c76 */
/* bench 1316.2.4 6042002065f9 */
/* bench 1316.2.5 4738d673b456 */
/* bench 1316.2.6 25e31c22c716 */
/* bench 1316.2.7 86313b9c1f1d */
/* bench 1316.2.8 32bf7e02fb59 */
/* bench 1316.2.9 dc5cc24e99cd */
/* bench 1316.2.10 6f228f566d0d */
	audio-codec@4c {
		compatible = "ti,pcm1789";
		reg = <0x4c>;
		reset-gpios = <&gpio2 14 GPIO_ACTIVE_LOW>;
		#sound-dai-cells = <0>;
	};
