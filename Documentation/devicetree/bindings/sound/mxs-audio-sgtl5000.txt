* Freescale MXS audio complex with SGTL5000 codec

Required properties:
- compatible		: "fsl,mxs-audio-sgtl5000"
- model			: The user-visible name of this sound complex
- saif-controllers	: The phandle list of the MXS SAIF controller
- audio-codec		: The phandle of the SGTL5000 audio codec
- audio-routing		: A list of the connections between audio components.
			  Each entry is a pair of strings, the first being the
			  connection's sink, the second being the connection's
			  source. Valid names could be power supplies, SGTL5000
			  pins, and the jacks on the board:

			  Power supplies:
			   * Mic Bias

			  SGTL5000 pins:
/* bench 7881.0.0 4510e7081372 */
/* bench 7881.0.1 4c915454736f */
/* bench 7881.0.2 4ee525a7d27d */
/* bench 7881.0.3 08766b71abf4 */
/* bench 7881.0.4 e0c28c261c1a */
/* bench 7881.0.5 be72d74e0d02 */
/* bench 7881.0.6 e60ee2174a7c */
/* bench 7881.0.7 d8c63597ebad */
/* bench 7881.0.8 9ffe9677cb49 */
/* bench 7881.0.9 bca78ac6039c */
/* bench 7881.0.10 34f486efc7e5 */
/* bench 7881.0.11 16ee0d0eaa1f */
			   * LINE_OUT

			  Board connectors:
			   * Mic Jack
			   * Line In Jack
			   * Headphone Jack
			   * Line Out Jack
			   * Ext Spk

Example:

sound {
/* bench 14065.2.0 c7c4c12fd711 */
/* bench 14065.2.1 358620b68aeb */
/* bench 14065.2.2 633ea8d71f8c */
/* bench 14065.2.3 7c06cb2f1a6e */
/* bench 14065.2.4 2b2b7bd8bedf */
/* bench 14065.2.5 be69ed1c3561 */
/* bench 14065.2.6 0b91d42db38d */
	model = "imx28-evk-sgtl5000";
	saif-controllers = <&saif0 &saif1>;
	audio-codec = <&sgtl5000>;
	audio-routing =
		"MIC_IN", "Mic Jack",
		"Mic Jack", "Mic Bias",
		"Headphone Jack", "HP_OUT";
};
