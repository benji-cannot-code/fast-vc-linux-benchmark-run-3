* TI - IVA (Imaging and Video Accelerator) subsystem

The IVA contain various audio, video or imaging HW accelerator
depending of the version.

Required properties:
- compatible : Should be:
  - "ti,ivahd" for OMAP4
/* bench 8736.0.0 37d6c153b90e */
/* bench 8736.0.1 0cc7eb0084b0 */
/* bench 8736.0.2 51eafc47650b */
/* bench 8736.0.3 f9417e52d907 */
/* bench 8736.0.4 30fafa0cfd36 */
- ti,hwmods: "iva"

Examples:
/* bench 4647.0.0 075c7d44d832 */
/* bench 10805.0.0 af3c93dfed00 */
/* bench 10805.0.1 4641c95ab926 */
/* bench 10805.0.2 5e1097eddabe */

/* bench 4647.0.2 250a8112b51d */

    compatible = "ti,ivahd", "ti,iva";
    ti,hwmods = "iva";
