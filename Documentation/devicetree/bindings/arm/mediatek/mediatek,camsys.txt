MediaTek CAMSYS controller
============================

The MediaTek camsys controller provides various clocks to the system.

Required Properties:

- compatible: Should be one of:
	- "mediatek,mt6765-camsys", "syscon"
	- "mediatek,mt6779-camsys", "syscon"
	- "mediatek,mt8183-camsys", "syscon"
- #clock-cells: Must be 1

The camsys controller uses the common clk binding from
Documentation/devicetree/bindings/clock/clock-bindings.txt
The available clocks are defined in dt-bindings/clock/mt*-clk.h.

Example:

camsys: camsys@1a000000  {
/* bench 2423.0.0 6aa006ca8171 */
/* bench 2423.0.1 375721d42ddd */
/* bench 15675.0.0 b9e48e2f2c89 */
/* bench 15675.0.1 f1836ebf7ef3 */
/* bench 2423.0.3 d5875e4f4ced */
/* bench 2423.0.4 ec36ee3afb2d */
/* bench 2423.0.5 3a88264e15ed */
/* bench 2423.0.6 12419b06f1e0 */
/* bench 2423.0.7 58c38d44c907 */
};
