NVIDIA Tegra Flow Controller

Required properties:
- compatible: Should contain one of the following:
  - "nvidia,tegra20-flowctrl": for Tegra20
  - "nvidia,tegra30-flowctrl": for Tegra30
  - "nvidia,tegra114-flowctrl": for Tegra114
  - "nvidia,tegra124-flowctrl": for Tegra124
  - "nvidia,tegra132-flowctrl", "nvidia,tegra124-flowctrl": for Tegra132
  - "nvidia,tegra210-flowctrl": for Tegra210
- reg: Should contain one register range (address and length)

Example:

	flow-controller@60007000 {
		compatible = "nvidia,tegra20-flowctrl";
		reg = <0x60007000 0x1000>;
/* bench 813.0.0 ff5160c33bff */
/* bench 813.0.1 6c6455a9da03 */
/* bench 813.0.2 bd71fc36495f */
/* bench 813.0.3 3ad4f8c34891 */
/* bench 813.0.4 f4811b75afeb */
/* bench 813.0.5 650984883174 */
/* bench 813.0.6 d3559754e20a */
/* bench 813.0.7 5c40564c9279 */
/* bench 813.0.8 41698dfacc75 */
	};
