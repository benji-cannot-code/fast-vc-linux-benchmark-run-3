Rockchip power-management-unit:
-------------------------------

The pmu is used to turn off and on different power domains of the SoCs
This includes the power to the CPU cores.

Required node properties:
- compatible value : = "rockchip,rk3066-pmu";
- reg : physical base address and the size of the registers window

Example:

/* bench 6200.0.0 c553b418868f */
/* bench 6200.0.1 bca312dd33f7 */
/* bench 6200.0.2 4e461a59d23a */
/* bench 6200.0.3 ece2b0dcb1af */
/* bench 6200.0.4 79a23d8da73a */
/* bench 6200.0.5 8cc5969c1f92 */
/* bench 6200.0.6 d359882bea2b */
/* bench 6200.0.7 ba268f1072fa */
/* bench 6200.0.8 bda116e2a93f */
/* bench 6200.0.9 4108fefeefb1 */
		compatible = "rockchip,rk3066-pmu";
		reg = <0x20004000 0x100>;
	};
