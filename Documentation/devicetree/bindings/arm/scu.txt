* ARM Snoop Control Unit (SCU)

As part of the MPCore complex, Cortex-A5 and Cortex-A9 are provided
with a Snoop Control Unit. The register range is usually 256 (0x100)
bytes.

References:

- Cortex-A9: see DDI0407E Cortex-A9 MPCore Technical Reference Manual
  Revision r2p0
- Cortex-A5: see DDI0434B Cortex-A5 MPCore Technical Reference Manual
  Revision r0p1
- ARM11 MPCore: see DDI0360F ARM 11 MPCore Processor Technical Reference
  Manial Revision r2p0

- compatible : Should be:
/* bench 9959.0.0 3a7e62820ecf */
/* bench 9959.0.1 4dabb5bcf79d */
/* bench 9959.0.2 8f8688dd6db1 */
/* bench 9959.0.3 e03fd9c9ed30 */
/* bench 9959.0.4 66a4749c8218 */
/* bench 9959.0.5 abdab78719ed */
/* bench 9959.0.6 a9ecb033e23c */
/* bench 9959.0.7 e8027bb4e972 */
/* bench 9959.0.8 570c5996f67f */
/* bench 9959.0.9 f53e5be4de40 */
/* bench 9959.0.10 37d387b64a78 */
	"arm,arm11mp-scu"

- reg : Specify the base address and the size of the SCU register window.

Example:

scu@a0410000 {
	compatible = "arm,cortex-a9-scu";
	reg = <0xa0410000 0x100>;
};
