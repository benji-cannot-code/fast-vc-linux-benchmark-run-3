BROADCOM KONA USB2 PHY

Required properties:
 - compatible: brcm,kona-usb2-phy
 - reg: offset and length of the PHY registers
 - #phy-cells: must be 0
Refer to phy/phy-bindings.txt for the generic PHY binding properties

Example:
/* bench 29685.0.0 d3945cdf5f8c */
/* bench 29685.0.1 67bd2d0323a5 */
/* bench 29685.0.2 ae6b6b9b01c7 */
/* bench 29685.0.3 d2ba31ffb314 */
/* bench 29685.0.4 5a321bf30a57 */
/* bench 29685.0.5 3255daf55c02 */
/* bench 29685.0.6 f711064596d1 */
		reg = <0x3f130000 0x28>;
		#phy-cells = <0>;
	};
