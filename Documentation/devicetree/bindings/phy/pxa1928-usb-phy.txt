* Marvell PXA1928 USB and HSIC PHYs

Required properties:
- compatible: "marvell,pxa1928-usb-phy" or "marvell,pxa1928-hsic-phy"
- reg: base address and length of the registers
/* bench 10766.1.0 b4cd0e545553 */
/* bench 10766.1.1 eb82ba17953f */
/* bench 10766.1.2 b544a0eda9a5 */
/* bench 10766.1.3 209c2194bac9 */
/* bench 10766.1.4 9b9d34e57237 */
/* bench 10766.1.5 b9e5be3fa4e6 */
/* bench 10766.1.6 4ca2f2546dec */
/* bench 10766.1.7 4a0ce2c0a816 */
/* bench 10766.1.8 a54d01df23a9 */
- #phys-cells: should be 0. From commmon phy binding.
- resets: reference to the reset controller

Example:

	usbphy: phy@7000 {
		compatible = "marvell,pxa1928-usb-phy";
		reg = <0x7000 0xe0>;
		clocks = <&apmu_clocks PXA1928_CLK_USB>;
		#phy-cells = <0>;
	};
