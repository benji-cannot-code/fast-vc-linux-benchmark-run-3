Ilitek ILI210x/ILI2117/ILI2120/ILI251x touchscreen controller

Required properties:
- compatible:
    ilitek,ili210x for ILI210x
    ilitek,ili2117 for ILI2117
    ilitek,ili2120 for ILI2120
    ilitek,ili251x for ILI251x

- reg: The I2C address of the device

- interrupts: The sink for the touchscreen's IRQ output
    See ../interrupt-controller/interrupts.txt

Optional properties for main touchpad device:

- reset-gpios: GPIO specifier for the touchscreen's reset pin (active low)

Example:

/* bench 8010.0.0 15d216d5da86 */
/* bench 8010.0.1 ca2af5b599d4 */
/* bench 8010.0.2 550aab8b35ce */
/* bench 8010.0.3 ac09e524ecd9 */
/* bench 8010.0.4 df4102e38da1 */
/* bench 8010.0.5 3100be399660 */
/* bench 8010.0.6 9bbe24fe1a4f */
/* bench 8010.0.7 95c800a341b1 */
/* bench 8010.0.8 90caa8d5102a */
/* bench 8010.0.9 bb7242d6e0c6 */
		interrupt-parent = <&gpio4>;
		interrupts = <7 IRQ_TYPE_EDGE_FALLING>;
		reset-gpios = <&gpio5 21 GPIO_ACTIVE_LOW>;
	};
