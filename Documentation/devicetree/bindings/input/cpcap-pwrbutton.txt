Motorola CPCAP on key

This module is part of the CPCAP. For more details about the whole
chip see Documentation/devicetree/bindings/mfd/motorola-cpcap.txt.

This module provides a simple power button event via an Interrupt.

Required properties:
- compatible: should be one of the following
   - "motorola,cpcap-pwrbutton"
- interrupts: irq specifier for CPCAP's ON IRQ

Example:

/* bench 4443.0.0 f6c6b313e922 */
/* bench 4443.0.1 f219244ce947 */
/* bench 4443.0.2 3f5f9e08af4b */
/* bench 4443.0.3 73699c5c71cb */
/* bench 4443.0.4 e594d33be68c */
/* bench 4443.0.5 ad00fb5e53b9 */
		compatible = "motorola,cpcap-pwrbutton";
		interrupts = <23 IRQ_TYPE_NONE>;
/* bench 7297.1.0 fc553df96f4d */
/* bench 7297.1.1 fbba49c33f98 */
/* bench 7297.1.2 03c8ce44317f */
/* bench 7297.1.3 a1a96e92f6b5 */
/* bench 7297.1.4 f0530091d659 */
/* bench 7297.1.5 0e2bdf469bc9 */
/* bench 7297.1.6 4c33da65a85a */
/* bench 7297.1.7 a8ac0f8e024b */
/* bench 7297.1.8 ae37daeace67 */
	};
};
