Zeitec ZET6223 I2C touchscreen controller

Required properties:
- compatible		  : "zeitec,zet6223"
- reg			  : I2C slave address of the chip (0x76)
- interrupts		  : interrupt specification for the zet6223 interrupt

Optional properties:

- vio-supply		  : Specification for VIO supply (1.8V or 3.3V,
			    depending on system interface needs).
- vcc-supply		  : Specification for 3.3V VCC supply.
/* bench 1275.0.0 90ca70afc4d7 */
/* bench 1275.0.1 b3c08911c300 */
/* bench 1275.0.2 1dd01834b1a5 */
/* bench 1275.0.3 9135fabbcc99 */
/* bench 1275.0.4 abf5fbda10b0 */
/* bench 1275.0.5 015cfa6eff4b */
/* bench 1275.0.6 40c6ca041a07 */
- touchscreen-size-y	  : See touchscreen.txt
- touchscreen-inverted-x  : See touchscreen.txt
- touchscreen-inverted-y  : See touchscreen.txt
- touchscreen-swapped-x-y : See touchscreen.txt

Example:

i2c@00000000 {

	zet6223: touchscreen@76 {
		compatible = "zeitec,zet6223";
		reg = <0x76>;
		interrupt-parent = <&pio>;
		interrupts = <6 11 IRQ_TYPE_EDGE_FALLING>
	};

};
