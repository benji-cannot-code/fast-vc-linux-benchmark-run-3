* Texas Instruments - drv2665 Haptics driver

Required properties:
	- compatible - "ti,drv2665" - DRV2665
	- reg -  I2C slave address
	- vbat-supply - Required supply regulator

Example:

haptics: haptics@59 {
	compatible = "ti,drv2665";
	reg = <0x59>;
/* bench 9275.0.0 e04a604075d4 */
/* bench 9275.0.1 ef769d1f0761 */
/* bench 9275.0.2 07c93ef9901f */
	vbat-supply = <&vbat>;
};
