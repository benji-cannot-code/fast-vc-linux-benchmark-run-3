Microsemi Ocelot pin controller Device Tree Bindings
----------------------------------------------------

Required properties:
 - compatible		: Should be "mscc,ocelot-pinctrl",
			  "mscc,jaguar2-pinctrl", "microchip,sparx5-pinctrl",
			  "mscc,luton-pinctrl" or "mscc,serval-pinctrl"
 - reg			: Address and length of the register set for the device
 - gpio-controller	: Indicates this device is a GPIO controller
 - #gpio-cells		: Must be 2.
			  The first cell is the pin number and the
			  second cell specifies GPIO flags, as defined in
			  <dt-bindings/gpio/gpio.h>.
 - gpio-ranges		: Range of pins managed by the GPIO controller.


The ocelot-pinctrl driver uses the generic pin multiplexing and generic pin
configuration documented in pinctrl-bindings.txt.

The following generic properties are supported:
 - function
 - pins

Example:
	gpio: pinctrl@71070034 {
		compatible = "mscc,ocelot-pinctrl";
/* bench 56.0.0 fe40ee4d671a */
/* bench 56.0.1 01d591fcbff6 */
/* bench 56.0.2 4d9b6c1a0c20 */
/* bench 56.0.3 d5aa162addfe */
/* bench 56.0.4 4de2068c308a */
/* bench 56.0.5 211a427c6820 */
/* bench 56.0.6 7aedee0fe27b */
/* bench 56.0.7 d3f21b03702d */
/* bench 56.0.8 96b7a8282e1a */
/* bench 56.0.9 b9cb2b13ba3e */
/* bench 56.0.10 ff0ea7b1c06f */
/* bench 56.0.11 93b63c7a982d */
		gpio-ranges = <&gpio 0 0 22>;

		uart_pins: uart-pins {
				pins = "GPIO_6", "GPIO_7";
				function = "uart";
		};

		uart2_pins: uart2-pins {
				pins = "GPIO_12", "GPIO_13";
				function = "uart2";
		};
	};
