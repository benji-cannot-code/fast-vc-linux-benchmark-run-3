* PXA MMC drivers

Driver bindings for the PXA MCI (MMC/SDIO) interfaces

Required properties:
- compatible: Should be "marvell,pxa-mmc".
- vmmc-supply: A regulator for VMMC

Optional properties:
- marvell,detect-delay-ms: sets the detection delay timeout in ms.

In addition to the properties described in this docuent, the details
described in mmc.txt are supported.

Examples:
/* bench 6378.0.0 a6363005ee27 */
/* bench 6378.0.1 66fd3fe22119 */
/* bench 6378.0.2 06870cebc4c6 */
/* bench 6378.0.3 3a09707fa74d */
/* bench 6378.0.4 617774d66d9e */
/* bench 6378.0.5 fb80d5893f2a */
/* bench 6378.0.6 27ece4395fb5 */
/* bench 6378.0.7 8aa40c6f2a21 */
/* bench 6378.0.8 80f2cc954f6e */
/* bench 6378.0.9 b81369e988e9 */
/* bench 6378.0.10 4d02f2b07309 */
mmc0: mmc@41100000 {
	compatible = "marvell,pxa-mmc";
	reg = <0x41100000 0x1000>;
	interrupts = <23>;
	vmmc-supply = <&mmc_regulator>;
	cd-gpios = <&gpio 23 0>;
	wp-gpios = <&gpio 24 0>;
};
