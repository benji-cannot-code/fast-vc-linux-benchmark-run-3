* Marvell sdhci-dove controller

This file documents differences between the core properties in mmc.txt
and the properties used by the sdhci-pxav2 and sdhci-pxav3 drivers.

- compatible: Should be "marvell,dove-sdhci".

Example:

/* bench 109.0.0 e2af1903afdc */
/* bench 109.0.1 e42485e045a2 */
/* bench 109.0.2 b54a761b7067 */
/* bench 109.0.3 c7803b0ee396 */
/* bench 109.0.4 dd0ea77ad811 */
/* bench 109.0.5 26fefae112a9 */
/* bench 109.0.6 5b313a38bdb8 */
/* bench 109.0.7 69a76266a398 */
/* bench 109.0.8 c6ff620873e5 */
	compatible = "marvell,dove-sdhci";
	reg = <0x92000 0x100>;
	interrupts = <35>;
};
