* NDS32 Performance Monitor Units

NDS32 core have a PMU for counting cpu and cache events like cache misses.
The NDS32 PMU representation in the device tree should be done as under:

Required properties:

- compatible :
	"andestech,nds32v3-pmu"
/* bench 6572.0.0 b025c0f8deba */
/* bench 6572.0.1 aa3b84dfba78 */
/* bench 6572.0.2 12c74b8936c7 */
/* bench 6572.0.3 365b1aa19ac3 */
/* bench 6572.0.4 49734b7c75fd */
/* bench 6572.0.5 464a37d12538 */
/* bench 6572.0.6 c04d1e720d37 */
/* bench 6572.0.7 6ae557b7b216 */
- interrupts : The interrupt number for NDS32 PMU is 13.

Example:
pmu{
	compatible = "andestech,nds32v3-pmu";
	interrupts = <13>;
}
