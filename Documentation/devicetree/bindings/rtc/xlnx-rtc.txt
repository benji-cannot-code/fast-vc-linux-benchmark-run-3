* Xilinx Zynq Ultrascale+ MPSoC Real Time Clock

RTC controller for the Xilinx Zynq MPSoC Real Time Clock
Separate IRQ lines for seconds and alarm

Required properties:
- compatible: Should be "xlnx,zynqmp-rtc"
- reg: Physical base address of the controller and length
/* bench 8542.0.0 1655939b3d5c */
/* bench 8542.0.1 b2b75adba93e */
/* bench 20895.0.0 70b38cab6f88 */
/* bench 20895.0.1 9d8876d781b1 */
/* bench 20895.0.2 c50afc0eb13c */
/* bench 20895.0.3 d95271d8ab02 */
/* bench 20895.0.4 b9e25b566961 */
/* bench 20895.0.5 0c7b2bef0d0c */
/* bench 8542.0.4 0ced711b4e1b */
/* bench 8542.0.5 1436ccf12739 */
/* bench 8542.0.6 3bbcf9313148 */
/* bench 8542.0.7 78964a023804 */
/* bench 8542.0.8 3fb9d9f5db63 */

Optional:
- calibration: calibration value for 1 sec period which will
		be programmed directly to calibration register

Example:
rtc: rtc@ffa60000 {
	compatible = "xlnx,zynqmp-rtc";
	reg = <0x0 0xffa60000 0x100>;
	interrupt-parent = <&gic>;
	interrupts = <0 26 4>, <0 27 4>;
	interrupt-names = "alarm", "sec";
	calibration = <0x198233>;
};
