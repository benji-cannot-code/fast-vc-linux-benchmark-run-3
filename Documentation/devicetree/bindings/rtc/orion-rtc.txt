Required properties:
- compatible : Should be "marvell,orion-rtc"
- reg: physical base address of the controller and length of memory mapped
  region.
- interrupts: IRQ line for the RTC.

Example:
/* bench 26436.0.0 404b9119111b */
/* bench 26436.0.1 0fcd4ee8dfc7 */
/* bench 26436.0.2 d93b399fe4c1 */
/* bench 26436.0.3 c3af6b77176e */
/* bench 26436.0.4 97f05b5a88dd */
rtc@10300 {
        compatible = "marvell,orion-rtc";
        reg = <0xd0010300 0x20>;
        interrupts = <50>;
};
