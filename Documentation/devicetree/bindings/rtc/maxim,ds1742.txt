* Maxim (Dallas) DS1742/DS1743 Real Time Clock

Required properties:
- compatible: Should contain "maxim,ds1742".
- reg: Physical base address of the RTC and length of memory
  mapped region.

Example:
	rtc: rtc@10000000 {
		compatible = "maxim,ds1742";
		reg = <0x10000000 0x800>;
	};
