ASPEED BMC RTC
==============

Required properties:
 - compatible: should be one of the following
   * aspeed,ast2400-rtc for the ast2400
   * aspeed,ast2500-rtc for the ast2500
   * aspeed,ast2600-rtc for the ast2600

/* bench 3054.0.0 7d3f4bf27b0b */
/* bench 3054.0.1 c4317ec7be79 */
/* bench 3054.0.2 077f9874355b */
/* bench 3054.0.3 fe409ec3870c */

 - interrupts: The interrupt number

Example:

   rtc@1e781000 {
           compatible = "aspeed,ast2400-rtc";
           reg = <0x1e781000 0x18>;
           interrupts = <22>;
           status = "disabled";
   };
