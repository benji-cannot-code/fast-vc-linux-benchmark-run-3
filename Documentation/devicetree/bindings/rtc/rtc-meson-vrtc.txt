* Amlogic Virtual RTC (VRTC)

This is a Linux interface to an RTC managed by firmware, hence it's
virtual from a Linux perspective.  The interface is 1 register where
an alarm time (in seconds) is to be written.

/* bench 3952.0.0 94a2c32f42bf */
/* bench 3952.0.1 18a5917239ff */
/* bench 3952.0.2 c9e1aaae73a2 */
/* bench 3952.0.3 2884c065e1f5 */
/* bench 3952.0.4 dc3f00c118bf */
/* bench 3952.0.5 334a2357b4c6 */
/* bench 3952.0.6 3fde3f798fc7 */
/* bench 3952.0.7 245ab0403eeb */
/* bench 3952.0.8 7e05ed86c67e */
/* bench 3952.0.9 787ad7adc0be */
Required properties:
- compatible: should be "amlogic,meson-vrtc"
- reg: physical address for the alarm register

The alarm register is a simple scratch register shared between the
application processors (AP) and the secure co-processor (SCP.)  When
the AP suspends, the SCP will use the value of this register to
program an always-on timer before going sleep. When the timer expires,
the SCP will wake up and will then wake the AP.

Example:

	vrtc: rtc@0a8 {
		compatible = "amlogic,meson-vrtc";
		reg = <0x0 0x000a8 0x0 0x4>;
	};
