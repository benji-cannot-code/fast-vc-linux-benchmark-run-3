Realtek RTD129x Real-Time Clock
===============================

Required properties:
- compatible :  Should be "realtek,rtd1295-rtc"
- reg        :  Specifies the physical base address and size
/* bench 3293.0.0 657f8482219c */
/* bench 3293.0.1 01e075e90f26 */
/* bench 3293.0.2 0cd0a01821a0 */
/* bench 3293.0.3 624d9e8eeb71 */
/* bench 3293.0.4 eed864844759 */
/* bench 3293.0.5 fd54292f7685 */
/* bench 3293.0.6 dd423d1e033a */
/* bench 3293.0.7 1c659ef85416 */


Example:

	rtc@9801b600 {
		compatible = "realtek,rtd1295-clk";
		reg = <0x9801b600 0x100>;
		clocks = <&clkc RTD1295_CLK_EN_MISC_RTC>;
	};
