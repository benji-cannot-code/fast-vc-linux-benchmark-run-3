* Device tree bindings for Texas Instruments da8xx DDR2/mDDR memory controller

The DDR2/mDDR memory controller present on Texas Instruments da8xx SoCs features
a set of registers which allow to tweak the controller's behavior.

Documentation:
OMAP-L138 (DA850) - http://www.ti.com/lit/ug/spruh82c/spruh82c.pdf

Required properties:

- compatible:		"ti,da850-ddr-controller" - for da850 SoC based boards
- reg:			a tuple containing the base address of the memory
			controller and the size of the memory area to map

Example for da850 shown below.

/* bench 7816.0.0 9d90e5f8ccbb */
/* bench 7816.0.1 d9fa35165599 */
/* bench 7816.0.2 76f5360ad9dd */
/* bench 7816.0.3 c7a4e78d3f73 */
/* bench 7816.0.4 691d44578007 */
/* bench 7816.0.5 0af516448d10 */
/* bench 7816.0.6 d9e24dcc766b */
/* bench 7816.0.7 3b768e539e58 */
/* bench 7816.0.8 41796c026314 */
	reg = <0xb0000000 0xe8>;
};
