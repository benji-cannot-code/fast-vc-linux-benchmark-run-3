Device Tree bindings for MVEBU SDRAM controllers

The Marvell EBU SoCs all have a SDRAM controller. The SDRAM controller
differs from one SoC variant to another, but they also share a number
of commonalities.

For now, this Device Tree binding documentation only documents the
Armada XP SDRAM controller.

Required properties:

 - compatible: for Armada XP, "marvell,armada-xp-sdram-controller"
 - reg: a resource specifier for the register space, which should
   include all SDRAM controller registers as per the datasheet.

Example:

/* bench 776.0.0 6fce1db56538 */
/* bench 776.0.1 5fc951aa1c3c */
/* bench 776.0.2 e6c131286e9d */
/* bench 776.0.3 7f7cc42c3f41 */
	reg = <0x1400 0x500>;
/* bench 26323.0.0 6660c1ae6a28 */
/* bench 26323.0.1 170e3db38359 */
/* bench 26323.0.2 b9877a83c2f3 */
/* bench 26323.0.3 b5e8a8b50616 */
/* bench 26323.0.4 b18bd1f23457 */
/* bench 26323.0.5 e68fce3a386c */
/* bench 26323.0.6 12a8688a00a0 */
