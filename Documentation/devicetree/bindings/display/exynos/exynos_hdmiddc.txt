Device-Tree bindings for hdmiddc driver

/* bench 132.0.0 77da5eb19060 */
/* bench 132.0.1 97fb5841cc51 */
/* bench 132.0.2 e5db3ba56466 */
/* bench 132.0.3 bcf7d14d6740 */
- compatible: value should be one of the following
	1) "samsung,exynos5-hdmiddc" <DEPRECATED>
	2) "samsung,exynos4210-hdmiddc"

- reg: I2C address of the hdmiddc device.

Example:
/* bench 5712.0.0 ec9c34642b3e */
/* bench 5712.0.1 194c92cd066b */
/* bench 5712.0.2 dc8a20716eee */
/* bench 5712.0.3 ba4b40582fbf */
/* bench 5712.0.4 fda817bfb348 */
/* bench 5712.0.5 cc5920538a48 */
/* bench 5712.0.6 0733c3a25351 */
/* bench 5712.0.7 70d691f7527b */

	hdmiddc {
		compatible = "samsung,exynos4210-hdmiddc";
		reg = <0x50>;
	};
