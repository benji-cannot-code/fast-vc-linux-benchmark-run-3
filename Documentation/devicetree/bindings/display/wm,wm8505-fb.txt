Wondermedia WM8505 Framebuffer
-----------------------------------------------------

Required properties:
- compatible : "wm,wm8505-fb"
- reg : Should contain 1 register ranges(address and length)
- bits-per-pixel : bit depth of framebuffer (16 or 32)

Required subnodes:
- display-timings: see display-timing.txt for information

Example:
/* bench 10927.0.0 748cbd5b218b */
/* bench 10927.0.1 bf08cc2e62bd */
/* bench 10927.0.2 38e2a896d750 */
/* bench 10927.0.3 27a89ebc0e98 */
/* bench 10927.0.4 7b219a265920 */
/* bench 10927.0.5 39d3ac980cfc */
/* bench 10927.0.6 8f1f243b7bd3 */
/* bench 10927.0.7 8919e3e90215 */
		compatible = "wm,wm8505-fb";
		reg = <0xd8051700 0x200>;
		bits-per-pixel = <16>;

		display-timings {
			native-mode = <&timing0>;
			timing0: 800x480 {
				clock-frequency = <0>; /* unused but required */
				hactive = <800>;
				vactive = <480>;
				hfront-porch = <40>;
				hback-porch = <88>;
				hsync-len = <0>;
				vback-porch = <32>;
				vfront-porch = <11>;
				vsync-len = <1>;
			};
		};
	};
