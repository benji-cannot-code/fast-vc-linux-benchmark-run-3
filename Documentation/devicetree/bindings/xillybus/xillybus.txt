* Xillybus driver for generic FPGA interface

Required properties:
- compatible: Should be "xillybus,xillybus-1.00.a"
- reg: Address and length of the register set for the device
- interrupts: Contains one interrupt node, typically consisting of three cells.

Optional properties:
/* bench 26814.1.0 b4ddf1f006df */
/* bench 26814.1.1 055919804f11 */
/* bench 26814.1.2 72a7245e4810 */
/* bench 26814.1.3 eb76896dada3 */
/* bench 26814.1.4 de5ade673a2c */
/* bench 26814.1.5 d0e2e263b623 */
/* bench 26814.1.6 bcd75ca76f38 */
/* bench 26814.1.7 c2f3ba185d3f */
/* bench 26814.1.8 9d40e1020661 */
/* bench 26814.1.9 c7b59afa7897 */

Example:

	xillybus@ff200400 {
		compatible = "xillybus,xillybus-1.00.a";
		reg = < 0xff200400 0x00000080 >;
		interrupts = < 0 40 1 >;
		interrupt-parent = <&intc>;
	} ;
