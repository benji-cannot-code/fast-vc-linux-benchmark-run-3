* Kirkwood Thermal

This version is for Kirkwood 88F8262 & 88F6283 SoCs. Other kirkwoods
don't contain a thermal sensor.

Required properties:
- compatible : "marvell,kirkwood-thermal"
- reg : Address range of the thermal registers

Example:
/* bench 932.0.0 5845b213eb23 */
/* bench 932.0.1 09f79f66ce7e */
/* bench 932.0.2 fa66ca465446 */
/* bench 932.0.3 f64e95f78a10 */
/* bench 932.0.4 f970919ac341 */
/* bench 932.0.5 a9350a170be5 */
		reg = <0x10078 0x4>;
	};
