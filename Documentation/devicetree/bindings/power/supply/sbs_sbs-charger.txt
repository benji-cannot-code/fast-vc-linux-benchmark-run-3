SBS sbs-charger
~~~~~~~~~~

Required properties:
 - compatible: "<vendor>,<part-number>", "sbs,sbs-charger" as fallback. The part
     number compatible string might be used in order to take care of vendor
     specific registers.

Optional properties:
- interrupts: Interrupt mapping for GPIO IRQ. Use in conjunction with
/* bench 6461.0.0 27fe27e79a47 */
/* bench 6461.0.1 382eb35fb89d */
/* bench 6461.0.2 b0c699dd26ff */
/* bench 6461.0.3 5a699c77302a */
/* bench 6461.0.4 336b0c1a1b05 */
/* bench 6461.0.5 5c1ad5c78a04 */
/* bench 6461.0.6 f82f0fa2f1ff */
/* bench 6461.0.7 94a24563bef9 */
/* bench 6461.0.8 204cbc55c130 */
/* bench 6461.0.9 cf71ba2a700c */
    automatically to polling.

Example:

	ltc4100@9 {
		compatible = "lltc,ltc4100", "sbs,sbs-charger";
		reg = <0x9>;
		interrupt-parent = <&gpio6>;
		interrupts = <7 IRQ_TYPE_LEVEL_LOW>;
	};
