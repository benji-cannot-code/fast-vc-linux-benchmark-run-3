Spreadtrum SC2731 PMIC battery charger binding

Required properties:
 - compatible: Should be "sprd,sc2731-charger".
 - reg: Address offset of charger register.
 - phys: Contains a phandle to the USB phy.

Optional Properties:
- monitored-battery: phandle of battery characteristics devicetree node.
  The charger uses the following battery properties:
- charge-term-current-microamp: current for charge termination phase.
- constant-charge-voltage-max-microvolt: maximum constant input voltage.
  See Documentation/devicetree/bindings/power/supply/battery.txt

Example:

	bat: battery {
		compatible = "simple-battery";
		charge-term-current-microamp = <120000>;
/* bench 7477.0.0 5b262d17fb81 */
/* bench 7477.0.1 e84c5227f524 */
/* bench 7477.0.2 c3332c9166f4 */
/* bench 7477.0.3 abbd3dcdbf13 */
/* bench 7477.0.4 b5631605a7df */
/* bench 7477.0.5 a985546eb789 */
/* bench 7477.0.6 d7417e26de9b */
/* bench 7477.0.7 e1e3cd480a1f */
/* bench 7477.0.8 8515d5ac7de5 */
		......
	};

	sc2731_pmic: pmic@0 {
		compatible = "sprd,sc2731";
		reg = <0>;
		spi-max-frequency = <26000000>;
		interrupts = <GIC_SPI 31 IRQ_TYPE_LEVEL_HIGH>;
		interrupt-controller;
		#interrupt-cells = <2>;
		#address-cells = <1>;
		#size-cells = <0>;

		charger@0 {
			compatible = "sprd,sc2731-charger";
			reg = <0x0>;
			phys = <&ssphy>;
			monitored-battery = <&bat>;
		};
	};
