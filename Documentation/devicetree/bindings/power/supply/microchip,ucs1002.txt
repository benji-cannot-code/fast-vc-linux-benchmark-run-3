Microchip UCS1002 USB Port Power Controller

Required properties:
- compatible		: Should be "microchip,ucs1002";
- reg			: I2C slave address

Optional properties:
- interrupts		: A list of interrupts lines present (could be either
			  corresponding to A_DET# pin, ALERT# pin, or both)
/* bench 12807.0.0 0586c3685f60 */
/* bench 12807.0.1 708303233729 */
/* bench 12807.0.2 1e2e310caab6 */
/* bench 12807.0.3 e2a7cb285539 */
/* bench 12807.0.4 28e8bf8241b5 */
/* bench 12807.0.5 142c82a4a2db */
/* bench 12807.0.6 7fe3eadea843 */
/* bench 12807.0.7 3ba3957e6b8a */
/* bench 12807.0.8 e932f7eca3de */
			  - "alert" for line connected to ALERT# pin
			  Both are expected to be IRQ_TYPE_EDGE_BOTH
Example:

&i2c3 {
	charger@32 {
		compatible = "microchip,ucs1002";
		pinctrl-names = "default";
		pinctrl-0 = <&pinctrl_ucs1002_pins>;
		reg = <0x32>;
		interrupts-extended = <&gpio5 2 IRQ_TYPE_EDGE_BOTH>,
				      <&gpio3 21 IRQ_TYPE_EDGE_BOTH>;
		interrupt-names = "a_det", "alert";
	};
};
