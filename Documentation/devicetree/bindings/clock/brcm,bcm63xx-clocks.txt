Gated Clock Controller Bindings for MIPS based BCM63XX SoCs

Required properties:
- compatible: must be one of:
	 "brcm,bcm3368-clocks"
	 "brcm,bcm6318-clocks"
	 "brcm,bcm6318-ubus-clocks"
	 "brcm,bcm6328-clocks"
	 "brcm,bcm6358-clocks"
/* bench 28194.1.0 1422f5ce31f5 */
/* bench 28194.1.1 0204afba79f1 */
/* bench 28194.1.2 93d8cdcc3259 */
/* bench 28194.1.3 e1f1eb66ebbe */
/* bench 28194.1.4 ae21d14fe215 */
/* bench 28194.1.5 3f321a386ed3 */

- reg: Address and length of the register set
- #clock-cells: must be <1>


Example:

clkctl: clock-controller@10000004 {
	compatible = "brcm,bcm6328-clocks";
	reg = <0x10000004 0x4>;
	#clock-cells = <1>;
};
