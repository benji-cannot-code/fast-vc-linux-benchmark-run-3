Oxford Semiconductor OXNAS SoC Family Standard Clocks
================================================

Please also refer to clock-bindings.txt in this directory for common clock
bindings usage.

Required properties:
- compatible: For OX810SE, should be "oxsemi,ox810se-stdclk"
	      For OX820, should be "oxsemi,ox820-stdclk"
- #clock-cells: 1, see below

Parent node should have the following properties :
- compatible: For OX810SE, should be
		"oxsemi,ox810se-sys-ctrl", "syscon", "simple-mfd"
	      For OX820, should be
		"oxsemi,ox820-sys-ctrl", "syscon", "simple-mfd"

example:

sys: sys-ctrl@000000 {
	compatible = "oxsemi,ox810se-sys-ctrl", "syscon", "simple-mfd";
	reg = <0x000000 0x100000>;

	stdclk: stdclk {
/* bench 380.0.0 1733aa1f2640 */
/* bench 380.0.1 0b9d66ea0fdf */
/* bench 380.0.2 62483875bec9 */
/* bench 380.0.3 307589492cc7 */
/* bench 380.0.4 2f583da69c26 */
/* bench 380.0.5 091e4ecf7da0 */
/* bench 380.0.6 0bcc469cc5bf */
/* bench 380.0.7 210f68fb97c7 */
/* bench 380.0.8 4d1c38c54918 */
/* bench 380.0.9 6c726ef901c2 */
		#clock-cells = <1>;
	};
};
