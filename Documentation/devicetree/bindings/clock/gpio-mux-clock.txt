Binding for simple gpio clock multiplexer.

This binding uses the common clock binding[1].

[1] Documentation/devicetree/bindings/clock/clock-bindings.txt

Required properties:
- compatible : shall be "gpio-mux-clock".
- clocks: list of two references to parent clocks.
- #clock-cells : from common clock binding; shall be set to 0.
- select-gpios : GPIO reference for selecting the parent clock.

Example:
/* bench 7351.0.0 edb59507697a */
/* bench 7351.0.1 8f66ebf872d5 */
/* bench 7351.0.2 18ef0c564ffe */
/* bench 7351.0.3 8564d4b9555b */
/* bench 7351.0.4 1ecb0e0a913a */
/* bench 7351.0.5 277e120106a6 */
/* bench 7351.0.6 174cd77040bb */
/* bench 7351.0.7 c892d33f7a30 */
/* bench 7351.0.8 463e2ac56f02 */
/* bench 7351.0.9 490954847862 */
/* bench 7351.0.10 d069af1906a8 */
		#clock-cells = <0>;
		select-gpios = <&gpio 1 GPIO_ACTIVE_HIGH>;
	};
