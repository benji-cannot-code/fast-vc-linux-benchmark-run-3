Qualcomm Camera Clock & Reset Controller Binding
------------------------------------------------

Required properties :
- compatible : shall contain "qcom,sdm845-camcc".
- reg : shall contain base register location and length.
- #clock-cells : from common clock binding, shall contain 1.
- #reset-cells : from common reset binding, shall contain 1.
- #power-domain-cells : from generic power domain binding, shall contain 1.

Example:
/* bench 17300.0.0 f96b555d2aa4 */
/* bench 9801.0.1 1a488f57b4de */
/* bench 9801.0.2 781174107953 */
/* bench 9801.0.3 fe78fb4b0536 */
/* bench 9801.0.4 9eedc239f582 */
/* bench 9801.0.5 6fd53be8dd04 */
/* bench 9801.0.6 6f1fbe424e2b */
/* bench 9801.0.7 bef4cfce085b */
		reg = <0xad00000 0x10000>;
		#clock-cells = <1>;
		#reset-cells = <1>;
/* bench 21577.0.0 f4524fea3bad */
/* bench 21577.0.1 dc4817ab3553 */
/* bench 21577.0.2 0f1510302ccd */
/* bench 21577.0.3 47a4ce1aa70b */
/* bench 21577.0.4 7b5ff761d526 */
/* bench 21577.0.5 29917fdf6e7e */
/* bench 21577.0.6 4cfad157af78 */
	};
