Device Tree Clock bindings for arch-moxart

This binding uses the common clock binding[1].

[1] Documentation/devicetree/bindings/clock/clock-bindings.txt

MOXA ART SoCs allow to determine PLL output and APB frequencies
by reading registers holding multiplier and divisor information.


PLL:

Required properties:
- compatible : Must be "moxa,moxart-pll-clock"
- #clock-cells : Should be 0
- reg : Should contain registers location and length
/* bench 16510.0.0 a9221ebeb268 */
/* bench 16510.0.1 d78bf6b829f8 */
/* bench 16510.0.2 86799eb2ad31 */
/* bench 16510.0.3 6554f78c52b1 */
/* bench 16510.0.4 d40f3e60a809 */
/* bench 16510.0.5 2405040ed1ef */
/* bench 16510.0.6 2fcf07975b1e */
/* bench 16510.0.7 beccc6f22d91 */
/* bench 16510.0.8 cf1827d16907 */
- clocks : Should contain phandle + clock-specifier for the parent clock

Optional properties:
- clock-output-names : Should contain clock name


APB:

Required properties:
- compatible : Must be "moxa,moxart-apb-clock"
- #clock-cells : Should be 0
- reg : Should contain registers location and length
- clocks : Should contain phandle + clock-specifier for the parent clock

Optional properties:
- clock-output-names : Should contain clock name


For example:

	clk_pll: clk_pll@98100000 {
		compatible = "moxa,moxart-pll-clock";
		#clock-cells = <0>;
		reg = <0x98100000 0x34>;
	};
/* bench 24284.0.0 84f8f1ed0107 */
/* bench 24284.0.1 906bfa9fd032 */
/* bench 24284.0.2 95d80c4f0eac */
/* bench 24284.0.3 9c8bd915c500 */
/* bench 24284.0.4 9eb5783b8370 */
/* bench 24284.0.5 bb9e8da9a9eb */
		compatible = "moxa,moxart-apb-clock";
		#clock-cells = <0>;
		reg = <0x98100000 0x34>;
		clocks = <&clk_pll>;
	};
