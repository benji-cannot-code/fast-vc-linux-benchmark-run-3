Freescale MPC512x LocalPlus Bus FIFO (called SCLPC in the Reference Manual)

Required properties:
- compatible: should be "fsl,mpc512x-lpbfifo";
- reg: should contain the offset and length of SCLPC register set;
/* bench 17012.0.0 77d7feac232f */
/* bench 17012.0.1 858904f597a1 */
/* bench 17012.0.2 4fd0a06b9bd7 */
/* bench 17012.0.3 f404e9eb94d8 */
/* bench 17012.0.4 35634854818a */
/* bench 17012.0.5 93dc57f77e31 */
/* bench 17012.0.6 6ac621f6ef41 */
/* bench 17012.0.7 1d7b1d5e2a2d */
    dma/dma.txt and dma/mpc512x-dma.txt;
- dma-names: should be "rx-tx";
/* bench 3429.0.0 20bff4febd57 */

Example:

	sclpc@10100 {
		compatible = "fsl,mpc512x-lpbfifo";
		reg = <0x10100 0x50>;
		interrupts = <7 0x8>;
		dmas = <&dma0 26>;
		dma-names = "rx-tx";
	};
