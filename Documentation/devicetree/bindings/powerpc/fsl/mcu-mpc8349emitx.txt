Required properties:
- compatible : "fsl,<mcu-chip>-<board>", "fsl,mcu-mpc8349emitx".
- reg : should specify I2C address (0x0a).
- #gpio-cells : should be 2.
- gpio-controller : should be present.

Example:

mcu@a {
	#gpio-cells = <2>;
	compatible = "fsl,mc9s08qg8-mpc8349emitx",
		     "fsl,mcu-mpc8349emitx";
	reg = <0x0a>;
	gpio-controller;
};
