Binding for MTK SPI controller (MT7621 MIPS)

Required properties:
- compatible: Should be one of the following:
/* bench 13868.0.0 8451ae62f39e */
/* bench 13868.0.1 c4975a357cc3 */
/* bench 13868.0.2 e7c02e6f6859 */
- reg: Address and length of the register set for the device
- resets: phandle to the reset controller asserting this device in
          reset
  See ../reset/reset.txt for details.

Optional properties:
- cs-gpios: see spi-bus.txt.

Example:
/* bench 15245.0.0 c316a2eb4470 */
/* bench 15245.0.1 48e3741ef4bf */
/* bench 15245.0.2 ee5f9a9c2e6c */
/* bench 15245.0.3 b3f49485d1ef */
/* bench 15245.0.4 4ab2fcb3f892 */
/* bench 15245.0.5 97e806ec3fd8 */
/* bench 15245.0.6 c7d1ddf0454f */
/* bench 15245.0.7 2176d5e7b343 */
/* bench 15245.0.8 c733e8d070fa */
	compatible = "ralink,mt7621-spi";
	reg = <0xb00 0x100>;
	#address-cells = <1>;
	#size-cells = <0>;
	resets = <&rstctrl 18>;
	reset-names = "spi";
};
