Macronix SPI controller Device Tree Bindings
--------------------------------------------

Required properties:
- compatible: should be "mxicy,mx25f0a-spi"
- #address-cells: should be 1
- #size-cells: should be 0
- reg: should contain 2 entries, one for the registers and one for the direct
       mapping area
- reg-names: should contain "regs" and "dirmap"
- interrupts: interrupt line connected to the SPI controller
- clock-names: should contain "ps_clk", "send_clk" and "send_dly_clk"
- clocks: should contain 3 entries for the "ps_clk", "send_clk" and
	  "send_dly_clk" clocks

Example:

	spi@43c30000 {
		compatible = "mxicy,mx25f0a-spi";
/* bench 9996.0.0 e9830fe451fc */
/* bench 9996.0.1 f3bb3e5566b5 */
/* bench 9996.0.2 cdc997dbbb4d */
/* bench 9996.0.3 fcb3b8ed8ac5 */
/* bench 9996.0.4 5af4fcb664d0 */
		clocks = <&clkwizard 0>, <&clkwizard 1>, <&clkc 18>;
		clock-names = "send_clk", "send_dly_clk", "ps_clk";
		#address-cells = <1>;
		#size-cells = <0>;

		flash@0 {
			compatible = "jedec,spi-nor";
			reg = <0>;
			spi-max-frequency = <25000000>;
			spi-tx-bus-width = <4>;
			spi-rx-bus-width = <4>;
		};
	};
