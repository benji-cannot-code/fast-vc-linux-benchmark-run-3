Broadcom BCM2835 auxiliar SPI1/2 controller

The BCM2835 contains two forms of SPI master controller, one known simply as
SPI0, and the other known as the "Universal SPI Master"; part of the
/* bench 11846.0.0 749fc41900cb */
/* bench 11846.0.1 b4898b3a35b0 */
/* bench 11846.0.2 45ab6e54f81d */
/* bench 11846.0.3 a581c7bca5e3 */
/* bench 11846.0.4 71c8effe8bb2 */
/* bench 11846.0.5 fc5fe2f9ba4b */
Required properties:
- compatible: Should be "brcm,bcm2835-aux-spi".
/* bench 5171.2.0 523a56c2f33a */
/* bench 5171.2.1 5b19a6559e8b */
/* bench 5171.2.2 a9a090d2d10f */
- interrupts: Should contain shared interrupt of the aux block
- clocks: The clock feeding the SPI controller - needs to
	  point to the auxiliar clock driver of the bcm2835,
	  as this clock will enable the output gate for the specific
	  clock.
- cs-gpios: the cs-gpios (native cs is NOT supported)
	    see also spi-bus.txt

Example:

spi1@7e215080 {
	compatible = "brcm,bcm2835-aux-spi";
	reg = <0x7e215080 0x40>;
	interrupts = <1 29>;
	clocks = <&aux_clocks BCM2835_AUX_CLOCK_SPI1>;
	#address-cells = <1>;
	#size-cells = <0>;
	cs-gpios = <&gpio 18>, <&gpio 17>, <&gpio 16>;
};

spi2@7e2150c0 {
	compatible = "brcm,bcm2835-aux-spi";
	reg = <0x7e2150c0 0x40>;
	interrupts = <1 29>;
	clocks = <&aux_clocks BCM2835_AUX_CLOCK_SPI2>;
	#address-cells = <1>;
	#size-cells = <0>;
	cs-gpios = <&gpio 43>, <&gpio 44>, <&gpio 45>;
};
