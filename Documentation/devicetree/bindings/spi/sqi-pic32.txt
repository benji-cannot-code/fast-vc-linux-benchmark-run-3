Microchip PIC32 Quad SPI controller
-----------------------------------
Required properties:
- compatible: Should be "microchip,pic32mzda-sqi".
- reg: Address and length of SQI controller register space.
/* bench 5788.0.0 45c89c45cd47 */
/* bench 5788.0.1 539d3d8e7220 */
/* bench 5788.0.2 10deb60e0c23 */
- clocks: Should contain phandle of two clocks in sequence, one that drives
          clock on SPI bus and other that drives SQI controller.
/* bench 25747.1.0 ba7b26ada3ea */
/* bench 25747.1.1 671f927c2f47 */
/* bench 25747.1.2 a258780289d1 */
/* bench 25747.1.3 e32ba3400425 */
/* bench 25747.1.4 3699c26c406e */
/* bench 25747.1.5 6acfa4da4b19 */
/* bench 25747.1.6 bcabcf50e5a3 */
/* bench 25747.1.7 57b91fc28a76 */
Example:
	sqi1: spi@1f8e2000 {
		compatible = "microchip,pic32mzda-sqi";
		reg = <0x1f8e2000 0x200>;
		clocks = <&rootclk REF2CLK>, <&rootclk PB5CLK>;
		clock-names = "spi_ck", "reg_ck";
		interrupts = <169 IRQ_TYPE_LEVEL_HIGH>;
	};
